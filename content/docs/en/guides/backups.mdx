title: "Back up and restore"
description: "Save your configuration in one file or move it to another computer."
---

Open **Settings → Backup** to save or restore the app’s configuration as a `.nvpnbackup` file.

## What is included

A backup contains settings, servers and subscriptions, routing, themes, fonts, and background pictures. It does not include this device’s synchronisation sign-in or device ID.

<Callout type="warn" title="Keep backups private">
Backups include connection information. Store them where only people who should have access to your servers can read them.
</Callout>

## Save a backup

Under **Save a backup**, choose **Save…** and select a location. Keep a copy before making large routing changes or moving to another machine.

## Restore a backup

Under **Restore a backup**, choose **Restore…**, read the replacement notice, and select the backup file.

Restoring replaces the current settings, servers, routing, and appearance with the backup’s contents. The app reloads afterwards. Save the current configuration first if you want to keep it.

After moving a backup to another computer, check platform-dependent settings such as application routing and file paths. Sign in to synchronisation again if you use it.

## Profiles across devices

**Settings → Synchronisation** can keep profiles the same across devices signed in to the same sync server. It serves a different purpose from a full backup: use the backup controls to preserve the broader app configuration.

For sharing only routing, export a [`.vflow` setup](/en/docs/guides/routing-setups#share-a-vflow-file).
