NuggetVPN is a VPN client for Windows, macOS, Linux, Android, and iOS. It connects to the servers you bring through a subscription, a share link, or a configuration file.

<Callout title="Bring your own connection">
NuggetVPN is the client. You need a working server or a subscription from your provider to connect.
</Callout>

## Find your way around

| In the app | What you can do |
| --- | --- |
| **Home** | Start or stop the VPN, see traffic, and run a speed test. |
| **Profiles & subscriptions** | Add connection sources and refresh subscriptions. |
| **Servers** | Search servers, mark favourites, and choose a server. |
| **Routing** | Decide which traffic uses the VPN, goes direct, or gets blocked. |
| **Activity → Network connections** | Inspect open connections and the rules that matched them. |
| **Activity → Statistics** | Review usage by app and server health over time. |
| **Activity → Logs** | Read diagnostics when logging is enabled. |
| **Settings** | Choose a core, customise the app, and manage backups and plugins. |

**Activity** groups Connections, Statistics, and Logs in a switcher.

Window layout and navigation placement depend on your platform and appearance settings. The guides use the English names from the app.

## Make it yours

Start with the [built-in core](/en/docs/reference/cores) for the broadest compatibility. Once connected, use the [routing guide](/en/docs/guides/routing) to send particular apps and websites where you want them. You can save different routes as [setups](/en/docs/guides/routing-setups) and switch between them.

The app also has a [command line](/en/docs/reference/cli), a [plugin SDK](/en/docs/plugins), and [source build instructions](/en/docs/developers/building). All proxy cores are embedded in the application; no separate core executable is downloaded at runtime.
