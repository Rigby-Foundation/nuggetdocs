یک **پروفایل** توضیح‌دهنده یک اتصال است. یک **اشتراک** یک URL است که مجموعه‌ای از سرورها را ارائه می‌دهد و وقتی ارائه‌دهنده آن‌ها را تغییر می‌دهد، می‌توان آن را به‌روزرسانی کرد.

## افزودن یک منبع [#add-a-source]

باز کردن **پروفایل‌ها و اشتراک‌ها → افزودن** و چسباندن اطلاعات اتصال خود.

| ورودی | چه اتفاقی می‌افتد |
| --- | --- |
| HTTP یا HTTPS URL اشتراک | اشتراک ارائه‌دهنده را دانلود می‌کند. |
| لینک اشتراک پروتکل | یک پروفایل فردی ایجاد می‌کند. |
| sing-box JSON | یک پیکربندی را وارد می‌کند. |
| Clash پیکربندی | توسط تحلیلگر پیکربندی پذیرفته شد؛ هنگامی که نیاز به اجرای یک پیکربندی کامل Clash به همان صورتی که ارائه شده، دارید از mihomo استفاده کنید. |
| تصویر QR | محتوای را برای بازبینی به گفتگو اضافه می‌کند. |

دیالوگ افزودن، URL‌های اشتراک، لینک‌های سرور و sing-box JSON را تبلیغ می‌کند. اگر یک فرمت یا پروتکل شکست خورد، آن را با [مرجع پروتکل](/fa/docs/reference/protocols) و [محدودیت‌های اصلی](/fa/docs/reference/cores) مقایسه کنید.

## به‌روزرسانی اشتراک [#refresh-a-subscription]

از کنترل تازه‌سازی روی کارت آن در **پروفایل‌ها و اشتراک‌ها** استفاده کنید. این کار فهرست سرور فعلی را از URL ارائه‌دهنده اصلی بازیابی می‌کند.

در **تنظیمات → رفتار** ، **به‌روزرسانی خودکار اشتراک‌ها** باعث تازه‌سازی در هنگام راه‌اندازی و در برنامه شش‌ساعته می‌شود. یک ارائه‌دهنده همچنین می‌تواند یک فاصله تازه‌سازی برای شما پیشنهاد دهد تا قبول کنید. خاموش کردن به‌روزرسانی خودکار اشتراک‌ها، تازه‌سازی خودکار برای هر اشتراک را غیرفعال می‌کند؛ تازه‌سازی دستی همچنان در دسترس است.

## استفاده، انقضا و پیام‌های ارائه‌دهنده [#usage-expiry-and-provider-messages]

NuggetVPN فقط زمانی داده‌های اختصاصی اشتراک، مصرف و تاریخ انقضا را نشان می‌دهد که ارائه‌دهنده آن‌ها را در پاسخ خود درج کرده باشد. مقادیر گمشده به این معنا نیست که اشتراک داده نامحدود یا بدون انقضا دارد.

ارائه‌دهندگان همچنین می‌توانند عنوان، برندینگ و اعلان‌ها ارائه دهند. این‌ها اشتراک را توصیف می‌کنند؛ آن‌ها متفاوت از شمارنده‌های ترافیک اندازه‌گیری‌شده محلی اپلیکیشن هستند.

## هویت اشتراک [#subscription-identity]

برخی ارائه‌دهندگان محدود می‌کنند که چه مشتریان یا دستگاه‌هایی می‌توانند یک اشتراک را دریافت کنند. **تنظیمات → هویت اشتراک** هویت مشتری و شناسه دستگاه استفاده‌شده برای این درخواست‌ها را کنترل می‌کند. اگر یک اشتراک معتبر رد شد، قبل از تغییر این مقادیر نیازمندی‌های ارائه‌دهنده خود را بررسی کنید.

## اشتراک‌گذاری، صادرات و حذف [#share-export-and-delete]

کنترل‌های منبع و پراکسی امکان اشتراک‌گذاری و صادرات را ارائه می‌دهند. لیست منابع همچنین پشتیبانی می‌کند از انتخاب چندین ورودی برای تازه‌سازی، کپی، صادرات یا حذف.

یک URL اشتراک، لینک سرور، کد QR یا پیکربندی صادرشده می‌تواند شامل اطلاعات ورود باشد. فقط با افرادی که باید قادر به استفاده از آن اتصال باشند به اشتراک بگذارید.

حذف یک منبع آن را از این نصب حذف می‌کند. برای حفظ پیکربندی کامل خود ابتدا [یک نسخه پشتیبان ذخیره کنید](/fa/docs/guides/backups).
