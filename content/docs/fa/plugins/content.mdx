محتوا به کد و مجوز نیاز ندارد: یک افزونه می‌تواند چیزی جز یک
`plugin.json` و چند فایل نباشد.

## قالب‌ها [#themes]

تم‌ها از همان شماره‌هایی استفاده می‌کنند که ویرایشگر تم در تنظیمات → ظاهر دارد. آسان‌ترین روش برای پیدا کردن مقادیر مورد علاقه‌تان این است که ابتدا تم را آنجا بسازید، سپس شماره‌های آن را کپی کنید.

```json
"themes": [
  {
    "id": "storm",
    "name": "Storm",
    "mode": "dark",
    "background": { "h": 250, "c": 0.03, "l": 0.14 },
    "accent": { "h": 190, "c": 0.13 },
    "image": {
      "file": "images/storm.jpg",
      "blur": 12,
      "brightness": 0.9,
      "saturate": 1,
      "dim": 0.35,
      "panel": 0.65
    }
  }
]
```

| فیلد | |
| --- | --- |
| `id` | منحصر به فرد درون افزونه، به همان شکل شناسه افزونه. |
| `name` | حداکثر ۶۰ کاراکتر، نمایش داده شده در انتخابگر تم. |
| `mode` | `"dark"` یا `"light"`. |
| `background.h` | رنگ صفحه، ۰–۳۶۰. |
| `background.c` | سایه، ۰–۰.۰۸. ۰ خاکستری است. |
| `background.l` | روشنایی: ۰–۰.۳ برای تم‌های تاریک، ۰.۹–۱ برای تم‌های روشن. |
| `accent.h` | رنگ دکمه‌ها، کلیدها و برجسته‌ها، ۰–۳۶۰. |
| `accent.c` | شدت رنگ متمایز، ۰–۰.۲۵. |
| `image` | اختیاری: یک تصویر پشت برنامه. |
| `image.file` | یک فایل PNG، JPEG، WebP یا GIF در افزونه. |
| `image.blur` | محو شدن بر حسب پیکسل، ۰–۴۰. |
| `image.brightness` | ۰.۳–۱.۵؛ ۱ همان حالت را حفظ می‌کند. |
| `image.saturate` | ۰–۲؛ ۰ به معنی سیاه و سفید است. |
| `image.dim` | میزان پوشش رنگ پس‌زمینه تم روی آن، ۰–۰.۹. |
| `image.panel` | میزان کدری پنل‌های برنامه روی آن، ۰.۲ (شیشه‌ای) تا ۱ (جامد). |

مقادیر خارج از محدوده خود به جای رد شدن، محدود می‌شوند. رنگ‌ها در OKLCH هستند و روشنی تأکید بر اساس حالت ثابت است، بنابراین متن روی دکمه‌ها همیشه قابل خواندن باقی می‌ماند.

## فونت‌ها [#fonts]

```json
"fonts": [
  { "name": "Weather Sans", "file": "fonts/weather-sans.woff2" }
]
```

TTF، OTF، WOFF یا WOFF2. هر فونت در فهرست فونت‌ها با نام خود ظاهر می‌شود و برای هر زبان ارائه می‌شود. حروفی که ندارد از فونت‌های جایگزین کشیده می‌شوند.

بررسی کنید که مجوز فونت اجازه انتشار مجدد آن را می‌دهد.

## تنظیمات مسیر‌یابی [#routing-setups]

```json
"routing": [
  {
    "name": "Streaming direct",
    "description": "Netflix, YouTube and Twitch outside the VPN.",
    "file": "routing/streaming.vflow"
  }
]
```

یک فایل `.vflow` یک نمودار کامل مسیر‌یابی است، همان فایلی که Routing → Export ذخیره می‌کند. تنظیمات را در برنامه ایجاد کنید، آن را صادر کنید و فایل را در پلاگین خود قرار دهید. استفاده از یکی از Routing → From plugins مسیر‌یابی کاربر را جایگزین می‌کند؛ کاربر می‌تواند آن را لغو کند.

تنظیماتی که به سرورهای خاص اشاره دارند، در کامپیوتر شخص دیگری آن لینک‌ها را از دست می‌دهند، زیرا سرورهای آن‌ها متفاوت است. قوانینی که ترافیک را "از طریق VPN"، "مستقیم" یا "مسدود" ارسال می‌کنند، همه جا کار می‌کنند.
