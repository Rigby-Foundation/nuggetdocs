<Callout title="محدودیت Android">
صفحه‌های افزونه در Android اجرا نمی‌شوند. پوسته‌ها، قلم‌ها و تنظیمات مسیریابی پشتیبانی می‌شوند.
</Callout>

یک افزونه یک فایل `.nuggetplugin` است: یک فایل زیپ با یک `plugin.json` در ریشه آن. می‌تواند فراهم کند:

| | مکان نمایش |
| --- | --- |
| **پوسته‌ها** | تنظیمات → ظاهر → تم، زیر "از افزونه‌ها" |
| **قلم‌ها** | فهرست فونت‌ها در تنظیمات → ظاهر |
| **تنظیمات مسیریابی** | مسیریابی → از پلاگین‌ها |
| **صفحه** | زیر پلاگین، در تنظیمات → پلاگین‌ها |
| **صفحهٔ پس‌زمینه** | هیچ‌جا: آن اجرا می‌شود، بدون دیده شدن، در حالی که پلاگین روشن است |

یک پلاگین با فقط تم‌ها، فونت‌ها و تنظیمات مسیریابی هیچ کدی اجرا نمی‌کند. صفحات ساده HTML و JavaScript هستند. آن‌ها در یک محیط محدود اجرا می‌شوند و از طریق یک پیام کوچک به برنامه می‌رسند API، و فقط برای آنچه کاربر هنگام نصب اجازه داده است.

## شروع سریع [#quick-start]

سریع‌ترین شروع، مثال در [`examples/plugins/glance`](https://github.com/Rigby-Foundation/NuggetVPN/tree/main/examples/plugins/glance) است. آن یک کارت وضعیت با دکمه اتصال، یک تم، و یک تنظیمات مسیریابی دارد که ردیاب‌های رایج را مسدود می‌کند:

```
glance/
├── plugin.json
├── icon.svg
├── panel.html
└── routing/
    └── trackers.vflow
```

آن را کپی کنید، `id` در `plugin.json` را به مقدار خود تغییر دهید، و آن را بسازید:

```bash
go run ./cmd/nuggetplugin path/to/your-plugin
```

این کنار پوشه `your-plugin.nuggetplugin` را می‌نویسد. افزونه را به همان روشی که برنامه هنگام نصب بررسی می‌کند، بررسی می‌کند، بنابراین هرگونه اشتباه ابتدا اینجا ظاهر می‌شود. سپس آن را در **تنظیمات → افزونه‌ها → نصب افزونه…** نصب کنید.

یک افزونه حداقلی که فقط یک تم اضافه می‌کند:

```json
{
  "format": 1,
  "id": "com.example.dusk",
  "name": "Dusk",
  "version": "1.0.0",
  "themes": [
    {
      "id": "dusk",
      "name": "Dusk",
      "mode": "dark",
      "background": { "h": 280, "c": 0.03, "l": 0.16 },
      "accent": { "h": 30, "c": 0.15 }
    }
  ]
}
```
