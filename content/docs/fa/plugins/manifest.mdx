هر پلاگین دارای یک `plugin.json` در ریشه فایل zip خود است.

```json
{
  "format": 1,
  "id": "com.example.weather",
  "name": "Server weather",
  "version": "1.0.0",
  "author": "You",
  "description": "What it does, in a sentence or two.",
  "homepage": "https://example.com/weather",
  "icon": "icon.png",

  "themes": [ … ],
  "fonts": [ … ],
  "routing": [ … ],

  "panel": { "title": "Weather", "file": "panel.html" },
  "background": "background.html",

  "permissions": ["state", "profiles", "notifications"],
  "network": ["status.example.com"]
}
```

## درباره پلاگین [#about-the-plugin]

| فیلد | ضروری | |
| --- | --- | --- |
| `format` | بله | همیشه `1`. یک برنامه جدیدتر ممکن است فرمت‌های جدیدتر را بخواند؛ این برنامه فرمت‌های دیگر را نمی‌پذیرد و این را اعلام می‌کند. |
| `id` | بله | شناسه دائمی پلاگین شما. از ۳–۶۴ حرف کوچک، ارقام، `.`، `-` و `_` استفاده کنید و با یک حرف یا رقم شروع و پایان دهید. یک دامنه معکوس خوب کار می‌کند: `com.example.weather`. یک به‌روزرسانی باید همان شناسه را حفظ کند. |
| `name` | بله | تا ۶۰ کاراکتر. |
| `version` | بله | هر رشته نسخه شامل حروف، ارقام، `.`، `+` و `-`، تا ۳۲ کاراکتر. نمایش به کاربر؛ برنامه نسخه‌ها را مقایسه نمی‌کند. |
| `author` | | تا ۸۰ کاراکتر. |
| `description` | | تا ۵۰۰ کاراکتر، در پنجره نصب و فهرست افزونه نمایش داده می‌شود. |
| `homepage` | | یک آدرس `https://`. نمایش داده می‌شود، هرگز توسط برنامه باز نمی‌شود. |
| `icon` | | یک فایل PNG، JPEG، WebP یا SVG در افزونه. به صورت مربع، در اندازه ۳۶–۴۰ پیکسل نمایش داده می‌شود. |

## محتوا [#content]

| فیلد | |
| --- | --- |
| `themes` | تم‌های سفارشی. مشاهده [محتوا](/fa/docs/plugins/content#themes). |
| `fonts` | فایل‌های فونت. مشاهده [محتوا](/fa/docs/plugins/content#fonts). |
| `routing` | تنظیمات مسیر `.vflow`. مشاهده [محتوا](/fa/docs/plugins/content#routing-setups). |

## صفحات [#pages]

| فیلد | |
| --- | --- |
| `panel` | `{ "title": "…", "file": "panel.html" }`: یک صفحه که در قسمت تنظیمات → افزونه‌ها زیر افزونه نمایش داده می‌شود. `title` تا ۴۰ کاراکتر است و به طور پیش‌فرض نام افزونه را دارد. |
| `background` | `"background.html"`: یک صفحه که در حالی که افزونه فعال است، در حال اجرا باقی می‌ماند. |

ببینید [نوشتن صفحات](/fa/docs/plugins/pages).

## دسترسی [#access]

| فیلد | |
| --- | --- |
| `permissions` | کارهایی که صفحات افزونه ممکن است انجام دهند. ببینید [مجوزها](/fa/docs/plugins/security#permissions). فقط برای چیزی که استفاده می‌کنید درخواست کنید؛ پنجره نصب همه آن‌ها را فهرست می‌کند. |
| `network` | نام‌های میزبان که صفحات شما ممکن است با آن‌ها تماس بگیرند، از طریق `https` و `wss`، مانند `api.example.com` یا `*.example.com`. هیچ چیز دیگری قابل دسترسی نیست. آدرس‌های IP، `localhost` و نام‌های محلی (`.local`، `.lan`، `.internal`، `.home.arpa`) رد می‌شوند. فقط برای افزونه‌هایی با یک صفحه مجاز است. |

## فایل‌ها [#files]

نام فایل‌ها می‌توانند از حروف، ارقام، `.`، `-` و `_` استفاده کنند، در پوشه‌ها که با `/` جدا شده‌اند. نام‌ها نمی‌توانند با نقطه شروع شوند. هر فایلی که فهرست نام می‌برد باید در پلاگین باشد و دارای نوع پسوند صحیح باشد.

یک پلاگین می‌تواند حداکثر 50 مگابایت باشد، با حداکثر 500 فایل که هر یک حداکثر 25 مگابایت باشد، و 80 مگابایت باز نشده.

فایل‌ها با نوعی که طبق پسوند تعیین می‌شود ارائه می‌شوند. هر چیز دیگری ارائه نمی‌شود:

`.html`، `.js`، `.mjs`، `.css`، `.json`، `.svg`، `.png`، `.jpg`، `.jpeg`، `.webp`، `.gif`، `.ttf`، `.otf`، `.woff`، `.woff2`، `.txt`
