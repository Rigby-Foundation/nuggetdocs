برنامه خود اپلیکیشن نیز به عنوان یک فرمان عمل می‌کند: از طریق ترمینال، اسکریپت یا میانبر صفحه‌کلید نسخه در حال اجرا را کنترل می‌کند.

```
NuggetVPN status
NuggetVPN connect Tokyo
NuggetVPN disconnect
```

اپلیکیشن باید در حال اجرا باشد (می‌تواند به سینی سیستم کوچک شده باشد). بدون اجرای اپلیکیشن، فرمان‌ها این موضوع را اعلام کرده و با کد 2 خارج می‌شوند.

## فرمان‌ها [#commands]

| فرمان | |
| --- | --- |
| `status` | اینکه آیا VPN فعال است، از طریق کدام سرور، برای چه مدت، و میزان ترافیک. |
| `connect [server]` | متصل می‌شود. به یک سرور، از طریق آی‌دی آن، نام دقیقش، یا بخشی از نامش که تنها با یک سرور مطابقت دارد. در صورت عدم تعیین، به آخرین سروری که استفاده شد متصل می‌شود. |
| `disconnect` | قطع اتصال می‌کند. |
| `servers [search]` | فهرست سرورها را نمایش می‌دهد، سرور جاری با `*` مشخص شده است، اختیاری فقط آن‌هایی که نامشان شامل `search` است. |
| `setup [name]` | فهرست تنظیمات مسیریابی را نمایش می‌دهد، تنظیم فعال با `*` مشخص شده است، یا به یکی از طریق نام سوئیچ می‌کند. |
| `speedtest` | یک تست سرعت از طریق سرور جاری اجرا می‌کند و دانلود، آپلود، پینگ و جیتِر را چاپ می‌کند. |
| `help` | فهرست دستورات را نمایش می‌دهد. |

`--json` را به هر دستور اضافه کنید تا به جای متن، JSON دریافت کنید، برای اسکریپت‌ها:

```
$ NuggetVPN status --json
{"status":"connected","profile_id":"p-de","profile":"Frankfurt 1","since":1790000000000}
```

## کدهای خروجی [#exit-codes]

| کد | |
| --- | --- |
| 0 | انجام شد. |
| 1 | برنامه رد کرد: سروری با این مشخصات وجود ندارد، برای تست سرعت متصل نیست و غیره. دلیل آن چاپ شده است. |
| 2 | برنامه در حال اجرا نیست. |

## جای برنامه [#where-the-program-is]

| سیستم | |
| --- | --- |
| Windows | `C:\Program Files\Rigby Foundation\NuggetVPN\NuggetVPN.exe`، یا جایی که آن را نصب کردید |
| macOS | `/Applications/NuggetVPN.app/Contents/MacOS/NuggetVPN` |
| Linux | `/usr/bin/NuggetVPN` از فایل .deb یا .rpm، یا خود AppImage |

در macOS، یک نام مستعار آن را آسان‌تر می‌کند:

```bash
alias nuggetvpn=/Applications/NuggetVPN.app/Contents/MacOS/NuggetVPN
```

### Windows [#windows]

NuggetVPN یک برنامه ویندوز است و Windows منتظر پایان آن‌ها نمی‌ماند. در `cmd`، پرامپت قبل از ظاهر شدن خروجی برمی‌گردد. در PowerShell، لوله‌کردن خروجی باعث می‌شود منتظر بماند:

```powershell
& "C:\Program Files\Rigby Foundation\NuggetVPN\NuggetVPN.exe" status | Write-Output
```

اسکریپت‌هایی که خروجی یا کد خروج را می‌خوانند، یا آن را هدایت می‌کنند، به حالت معمول کار می‌کنند.

## امنیت [#security]

برنامه در حال اجرا روی یک سوکت در پوشه کاربری خودتان گوش می‌دهد و هر دستور شامل توکنی از فایلی است که فقط حساب شما می‌تواند آن را بخواند. حساب‌های دیگر روی همان کامپیوتر نمی‌توانند از آن استفاده کنند.
