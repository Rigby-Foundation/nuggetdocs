---
title: "初めての接続"
description: "サブスクリプションまたはサーバーをインポートし、それを選択し、トンネルをオンラインにします。"
---

プロバイダーのサブスクリプションURLまたはサーバー共有リンクを用意してください。サブスクリプションは通常、`https://` URL です。単一のサーバーリンクは、`vless://`、`vmess://`、`trojan://`、または`ss://` のようなプロトコルで始まります。

<Steps>
<Step>
### 接続を追加する [#add-your-connection]

**プロファイルとサブスクリプション** を開き、 **追加** を選択するか、アプリのナビゲーションにある追加ボタンを使用します。 **プロファイルまたはサブスクリプションを追加** で、リンクを **接続リンクを貼り付け** に貼り付けます。

HTTP または HTTPS の URL の場合、ボタンは **サブスクリプションをインポート** になります。サーバーリンクまたは sing-box JSON の場合は、プロフィールに名前を付け、 **プロファイルを追加** を選択できます。
</Step>
<Step>
### ソースとサーバーを選択する [#choose-a-source-and-server]

追加したばかりのサブスクリプションまたはプロファイルを選択します。複数のサーバーがあるサブスクリプションの場合は、 **サーバー** を開き、サーバーを選択するか、自動選択を使用してください。単一の完全構成では、別個のサーバーリストがない場合があります。

設定が異なるコアを必要としない限り、 **設定 → コア** は **内蔵 sing-box** のままにしておきます。
</Step>
<Step>
### 接続 [#connect]

**ホーム** を開き、接続ボタンを押します。OS の VPN または管理者権限の確認を許可します。デスクトップでは、この確認によって現在のアプリセッション用のトンネルサービスが起動します。

**接続済み** になるまで待ちます。接続中に表示されるサーバーが、コアが実際に使用しているサーバーです。最速サーバのお勧め表示だけでは、VPNがアクティブであることを意味しません。
</Step>
<Step>
### 接続を確認します [#check-the-connection]

ウェブサイトを開き、リアルタイムのトラフィックカウンターを確認してください。 **ホーム** から速度テストを実行することも、 **ネットワーク接続** でリクエストを確認することもできます。

切断したいときは、再度接続ボタンを押してください。
</Step>
</Steps>

## QRコードからインポート [#import-from-a-qr-code]

追加ダイアログでは、ディスクから選択したQR画像やダイアログに貼り付けた画像を読み取ることができます。Androidでは、カメラを使用してスキャンすることもできます。デコードされたリンクを確認してからインポートしてください。

## 接続できない場合 [#if-it-does-not-connect]

サブスクリプションが有効期限切れでないか確認し、他のサーバーを試し、選択したコアがプロトコルをサポートしていることを確認してください。[トラブルシューティングガイド](/ja/docs/troubleshooting)には、ログを有効にして障害の原因を絞り込む方法が説明されています。
