title: "ショートカットと Wi-Fi ルール"

---

これらの制御はデスクトップに適用されます。AndroidはWi-Fiルール、グローバルショートカット、ログイン時の起動、またはコマンドラインを提供しません。

## グローバルショートカット [#global-shortcut]

**設定 → 動作 → ショートカット** でキーの組み合わせを設定します。ウィンドウが非表示でも、最後に選択したサーバーを使って接続または切断します。

ショートカットを削除するにはクリアコントロールを使用してください。他のアプリケーションと競合しない組み合わせを選んでください。

## Wi-Fiルール [#wi-fi-rules]

**設定 → Wi-Fi** を開いて、信頼されたネットワーク名を管理します。

- **信頼されていないネットワークで接続** は、信頼されていないWi-Fiネットワークに接続した際に最後に使用したサーバーに接続します。
- **信頼済みネットワークで切断** は、信頼されたネットワークに接続した際に切断します。

現在のネットワークには **信頼する** を使用するか、手動で信頼済みリストに名前を追加してください。信頼済みネットワークとは、VPNを必要としないと選択したネットワークのことで、その名前はセキュリティの保証ではありません。

### ネットワーク名が非表示の場合 [#if-the-network-name-is-hidden]

一部のオペレーティングシステムでは、Wi-Fi名を表示するために位置情報の権限が必要です。システムのプライバシー設定でアプリが読み取ることを許可するか、信頼済みネットワーク名を自分で入力してください。Wi-Fiの検索がサポートされていない場合、アプリが通知します。

## ターミナルとスクリプト [#terminal-and-scripts]

[コマンドライン](/ja/docs/reference/cli)は、すでに実行中のデスクトップインスタンスを制御します。

```bash
NuggetVPN status
NuggetVPN connect Tokyo
NuggetVPN setup Work
NuggetVPN disconnect
```

構造化された結果のために`--json`を追加し、終了コードで失敗を検出してください。アプリはトレイに最小化できますが、実行を続ける必要があります。

時間ベースのルーティング変更には、[ルーティングスケジュール](/ja/docs/guides/routing-setups#schedule-a-setup)を使用してください。
