## ライブトラフィック [#live-traffic]

**ホーム** 画面には、稼働中のコアから読み取ったトラフィックカウンターが表示されます。これらは、プロバイダーから提供されるサブスクリプションの許容量や有効期限の値とは別です。

## 開いている接続 [#open-connections]

**アクティビティ → ネットワーク接続** では、背後のプログラム、マッチしたルール、および使用されたサーバーとともに、ライブ接続が表示されます。この画面から個別の接続を閉じることができます。

ルーティング変更を確認する最適な場所はここです：アプリまたはサイトから新しいリクエストを作成し、その一致したルールとルートを確認します。ルーティングヒット数は、総計ではなく現在開かれている接続を表示します。

## 統計 [#statistics]

**アクティビティ → 統計** では、アプリケーションごとおよび日ごとのトラフィック、各サーバーの稼働時間と過去1日および1週間の遅延を確認できます。これらの統計はコンピュータに保存されます。

## スピードテスト [#speed-test]

接続中に **ホーム** からスピードテストを実行します。現在のサーバー経由で測定します。デスクトップユーザーは以下も実行できます：

```bash
NuggetVPN speedtest
```

コマンドはダウンロード、アップロード、ピング、ジッターを報告します。テストはデータを消費するため、プロバイダーの制限を考慮してください。

## ログ [#logs]

リリースビルドでは、ログはデフォルトでオフになっています。問題を診断する際は、 **ログをオンにする** の下で **アクティビティ → ログ** か、 **設定 → プライバシー** の下で有効にしてください。

1. ログ記録をオンにする。
2. 失敗した接続またはリクエストを再現してください。
3. **アクティビティ → ログ** ログを開き、エラーを確認してください。必要に応じて関連する診断情報をエクスポートしてください。
4. 終了したらログをオフにしてください。オフにすると、保存されたログも削除されます。

インターフェースが別の言語を使用していても、ログは英語のままです。問題に添付する前に、エクスポートされた診断情報にサーバーのアドレス、ドメイン、その他の個人情報が含まれていないか確認してください。

保存されたログの場所については、[ファイルとフォルダー](/ja/docs/reference/files)を参照してください。
