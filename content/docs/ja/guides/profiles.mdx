---
title: "プロファイルとサブスクリプション"
description: "接続ソースを追加し、サーバーを更新し、プロバイダー情報を理解します。"
---

**プロファイル** は接続を説明します。 **サブスクリプション** は、サーバーのコレクションを提供するURLで、プロバイダーが変更したときに更新できます。

## ソースを追加する [#add-a-source]

**プロファイルとサブスクリプション → 追加** を開き、接続情報を貼り付けます。

| 入力 | 結果 |
| --- | --- |
| HTTPまたはHTTPSサブスクリプションURL | プロバイダーのサブスクリプションをダウンロードします。 |
| プロトコル共有リンク | 個別のプロファイルを作成します。 |
| sing-box JSON | 設定をインポートします。 |
| Clash設定 | 設定パーサーによって受け入れられます。提供された完全なClash設定を実行する必要がある場合は、mihomoを使用してください。 |
| QR画像 | 内容をデコードして、レビュー用の追加ダイアログに表示します。 |

追加ダイアログは、購読URL、サーリンク、及びsing-boxJSONを宣伝します。形式やプロトコルが失敗した場合、[プロトコル参照](/ja/docs/reference/protocols)および[コア制限](/ja/docs/reference/cores)と比較してください。

## 購読を更新 [#refresh-a-subscription]

**プロファイルとサブスクリプション** のカードにある更新コントロールを使用してください。これにより、元の提供元URLから現在のサーバーリストを取得します。

**設定 → 動作** で、 **サブスクリプションを自動更新** を有効にすると、起動時および6時間ごとのスケジュールで更新されます。プロバイダーは受け入れる更新間隔を提案することもできます。自動サブスクリプション更新をオフにすると、すべてのサブスクリプションに対する自動更新が無効になりますが、手動更新は引き続き利用可能です。

## 利用状況、有効期限、プロバイダーのメッセージ [#usage-expiry-and-provider-messages]

NuggetVPN は、プロバイダーが応答に含めた場合にのみ、サブスクリプションのデータ容量、使用量、有効期限を表示します。値が欠落しているからといって、そのサブスクリプションが無制限データまたは有効期限なしであることを意味するわけではありません。

プロバイダーは、タイトル、ブランド、アナウンスも提供できます。これらはサブスクリプションを説明するもので、アプリのローカル測定トラフィックカウンターとは異なります。

## サブスクリプションの識別情報 [#subscription-identity]

一部のプロバイダーは、どのクライアントやデバイスがサブスクリプションを取得できるかを制限しています。 **設定 → サブスクリプションの識別情報** では、これらのリクエストに使用されるクライアント識別とデバイスIDを管理できます。もし有効なサブスクリプションが拒否される場合は、これらの値を変更する前にプロバイダーの要件を確認してください。

## 共有、エクスポート、削除 [#share-export-and-delete]

ソースとプロキシのコントロールは、共有とエクスポートを提供します。ソースリストでは、複数のエントリを選択して更新、コピー、エクスポート、または削除することも可能です。

サブスクリプションのURL、サーバーリンク、QRコード、またはエクスポートされた構成には資格情報が含まれる場合があります。その接続を使用できるべき人とだけ共有してください。

ソースを削除すると、このインストールからも削除されます。まず、[完全な構成を保存する](/ja/docs/guides/backups)ためにバックアップを作成してください。
