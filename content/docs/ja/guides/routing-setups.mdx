設定には完全なルーティング構成が含まれます。家庭用、仕事用、その他の用途に合わせて個別の設定を保持し、 **ルーティング** またはデスクトップトレイから切り替えます。

## 作成と切り替え [#create-and-switch]

**ルーティング** の設定コントロールを使用して、設定を作成、複製、名前変更、または削除します。名前を選ぶとアクティブになります。設定を削除するとそのすべてのルールが削除され、元に戻すことはできません。

デスクトップでは、[コマンドライン](/ja/docs/reference/cli)から設定を一覧表示したり切り替えたりできます。

```bash
NuggetVPN setup
NuggetVPN setup Work
```

## プリセットから開始 [#start-from-a-preset]

組み込みのプリセットには、広告とトラッカーのブロック、QUICのブロック、トレントの直接送信、VPNの回避（国単位）があります。

追加されたルールとその順序を確認してください。特に、 **トレントは直接** および **国を指定して直接** は、意図的にVPNの外にマッチするトラフィックを送信します。

## ジオデータとリモートリスト [#geo-data-and-remote-lists]

サービスおよび国のルールでは、カスタムGeoSiteおよびGeoIPデータを使用できます。ルーティングのジオデータコントロールを通じてファイルを管理してください。カテゴリーの提案は、読み込まれたデータに依存します。

リモートルールリストは、接続時にダウンロードされ、コアによって更新されることがあります。エディタはそのステータスを表示し、 **リストを今すぐ更新** の機能を提供します。選択したコアがフォーマットをサポートしていることを確認してください：mihomoはsing-box `.srs`および`.json`リストをスキップし、自身のジオデータを使用します。

## .vflow ファイルを共有する [#share-a-vflow-file]

**ルーティング → エクスポート** を使用してルーティング設定を保存し、 **インポート** を使用して読み込みます。`.vflow` ファイルにはルーティングが含まれており、アプリケーションの完全なバックアップではありません。

特定のサーバー宛先は、元のコンピューター上のプロファイルIDに依存します。他のインストールではこれらの参照が存在しない可能性があるため、インポート後に確認してください。汎用の VPN、直接、およびブロック宛先は共有が簡単です。

プラグインは **ルーティング → プラグインから** の設定を提供できます。設定を適用すると現在のルーティングが置き換えられ、この操作は元に戻すことができます。

## 設定をスケジュールする [#schedule-a-setup]

**ルーティング** のスケジュールコントロールは、曜日ごとに設定を切り替えることができます。設定、曜日、開始時間と終了時間を選択します。たとえば、平日の 09:00 から 18:00 まで **作業** を選択します。

コンピュータの時間またはタイムゾーンを変更した後、スケジュールを確認してください。アプリが実行されている必要があり、スケジュール管理が有効になります。
