NuggetVPN は Windows、macOS、Linux、Android、iOS 向けの VPN クライアントです。サブスクリプション、サーバーの共有リンク、設定ファイルを追加して、お使いのサーバーに接続します。

<Callout title="サーバーまたはサブスクリプションが必要です">
NuggetVPNがクライアントです。接続するには、作動中のサーバーかプロバイダーからのサブスクリプションが必要です。
</Callout>

## 使い方を見つける [#find-your-way-around]

| アプリ内で | できること |
| --- | --- |
| **ホーム** | VPNを開始または停止し、トラフィックを確認し、速度テストを実行します。 |
| **プロファイルとサブスクリプション** | 接続元を追加し、サブスクリプションを更新します。 |
| **サーバー** | サーバーを検索し、お気に入りをマークし、サーバーを選択します。 |
| **ルーティング** | どのトラフィックがVPNを使用するか、直接進むか、ブロックされるかを決定します。 |
| **アクティビティ → ネットワーク接続** | 開いている接続とそれにマッチしたルールを確認します。 |
| **アクティビティ → 統計** | アプリの利用状況とサーバーの稼働状況を時間ごとに確認します。 |
| **アクティビティ → ログ** | ロギングが有効な場合に診断情報を確認します。 |
| **設定** | コアを選択し、アプリをカスタマイズし、バックアップやプラグインを管理します。 |

**アクティビティ** は、接続、統計、ログを切り替えスイッチでまとめています。

ウィンドウとナビゲーションの配置はプラットフォームと外観の設定によって異なります。ガイド内の画面名と設定名は、アプリの日本語 UI に合わせています。

## 自分用にカスタマイズしましょう [#make-it-yours]

最も広い互換性のために、まず[組み込みのコア](/ja/docs/reference/cores)を使います。接続後は、[ルーティングガイド](/ja/docs/guides/routing)を使って、特定のアプリやウェブサイトを希望の場所へ送ることができます。異なるルートを[セットアップ](/ja/docs/guides/routing-setups)として保存し、それらを切り替えることも可能です。

このアプリには[コマンドライン](/ja/docs/reference/cli)、[プラグインSDK](/ja/docs/plugins)、そして[ソースビルドの手順](/ja/docs/developers/building)があります。すべてのプロキシコアはアプリケーション内に組み込まれており、実行時に別のコア実行ファイルをダウンロードする必要はありません。
