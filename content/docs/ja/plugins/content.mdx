コンテンツにはコードや権限は不要です：プラグインは`plugin.json`といくつかのファイルだけで構成されることができます。

## テーマ [#themes]

テーマは設定 → 外観のテーマエディタと同じ番号を使用します。自分の好みの値を見つける最も簡単な方法は、まずそこでテーマを作成し、その番号をコピーすることです。

```json
"themes": [
  {
    "id": "storm",
    "name": "Storm",
    "mode": "dark",
    "background": { "h": 250, "c": 0.03, "l": 0.14 },
    "accent": { "h": 190, "c": 0.13 },
    "image": {
      "file": "images/storm.jpg",
      "blur": 12,
      "brightness": 0.9,
      "saturate": 1,
      "dim": 0.35,
      "panel": 0.65
    }
  }
]
```

| フィールド | |
| --- | --- |
| `id` | プラグイン内でユニークで、プラグインIDと同じ形式です。 |
| `name` | 最大60文字、テーマピッカーに表示されます。 |
| `mode` | `"dark"`または`"light"`。 |
| `background.h` | ページの色相、0–360。 |
| `background.c` | ティント、0–0.08。0はグレー。 |
| `background.l` | 明度：ダークテーマは0–0.3、ライトテーマは0.9–1。 |
| `accent.h` | ボタン、スイッチ、およびハイライトの色相、0–360。 |
| `accent.c` | アクセントの鮮やかさ、0–0.25。 |
| `image` | オプション：アプリの背後に表示する画像。 |
| `image.file` | プラグイン内のPNG、JPEG、WebP、またはGIF。 |
| `image.blur` | ピクセル単位のぼかし、0–40。 |
| `image.brightness` | 0.3–1.5; 1はそのままにする。 |
| `image.saturate` | 0–2; 0は白黒。 |
| `image.dim` | テーマの背景色がどれくらい上塗りされるか、0–0.9。 |
| `image.panel` | アプリのパネルがどれくらい不透明か、0.2（ガラスのよう）から1（不透明）。 |

範囲外の値は拒否されるのではなく、クランプされます。色はOKLCHにあり、アクセントの明るさはモードごとに固定されているので、ボタン上のテキストは常に読みやすい状態が保たれます。

## フォント [#fonts]

```json
"fonts": [
  { "name": "Weather Sans", "file": "fonts/weather-sans.woff2" }
]
```

TTF、OTF、WOFF、または WOFF2。各フォントはその名前でフォントリストに表示され、すべての言語で使用可能です。不足している文字はフォールバックフォントから描画されます。

フォントのライセンスが再配布を許可していることを確認してください。

## ルーティング設定 [#routing-setups]

```json
"routing": [
  {
    "name": "Streaming direct",
    "description": "Netflix, YouTube and Twitch outside the VPN.",
    "file": "routing/streaming.vflow"
  }
]
```

`.vflow` ファイルは、Routing → Export で保存される同じファイルであり、ルーティング全体のグラフです。アプリで設定を構築し、エクスポートしてプラグインに置きます。Routing → From plugins からの使用はユーザーのルーティングを置き換えます；ユーザーはそれを元に戻すことができます。

特定のサーバーを参照する設定は、他人のコンピュータではそのリンクを失います。なぜなら、それぞれのサーバーが異なるからです。“VPN経由”、“直接”または“ブロック”を送信するルールは、どこでも機能します。
