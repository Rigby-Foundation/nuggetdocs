**設定 → コア** の中からコアを選択してください。デスクトップ版は同じバイナリに4つのコアを埋め込んでいるため、別途コア実行ファイルをインストールする必要はありません。アプリは各選択肢の隣に埋め込みバージョンを表示します。

アプリの機能を最も幅広くサポートするために、 **内蔵 sing-box** から始めてください。

## コアを比較する [#compare-cores]

| コア | 使用用途 | 制限 |
| --- | --- | --- |
| **内蔵 sing-box** | デフォルトのTodayCoreベースのエンジン、XHTTP、Reality、およびアプリの完全なルーティング機能セットを含む。 | `rigby://`は組み込みコアではサポートされていません。 |
| **公式 sing-box** | SagerNetのsing-box実装。 | XHTTPなし；これらのサーバーには組み込みまたはXrayが必要です。 |
| **mihomo** | Clash Metaおよび完全なClash設定。 | 検出されたプロトコルルールやsing-box `.srs` / `.json`ルールリストをスキップします。独自の地理データを使用します。アプリのTLS分割およびSNI設定は適用されません。 |
| **Xray** | 組み込みトンネル、DNSおよびルーティングによるXrayサーバーの処理。 | Hysteria、Hysteria2、TUIC、SSH のサーバーと Shadowsocks プラグインには非対応です。アプリの TLS フラグメンテーションと SNI の設定は適用されません。 |

## Android [#android]

Androidでは組み込みのコアとXrayのみが提供されます。組み込みのコアはAndroidのVpnServiceと統合され、Xrayはその背後で動作します。

## サポートされていないプロファイル [#unsupported-profiles]

アプリは選択されたコアに対して実行できないプロファイルを確認します。それらのプロファイルは、利用可能に見えて説明なしに失敗するのではなく、理由とともにマークされます。

サーバーが **別のコアが必要** とマークされている場合は、そのプロトコルとトランスポートをこの表と比較し、コアを切り替えて再試行してください。

## Xrayがどのように適合するか [#how-xray-fits-in]

Xray はアウトバウンドサーバー接続を処理し、組み込みのコアは TUN、DNS、ルーティング、およびキルスイッチを維持します。パスワードで保護されたループバックエントリーポイントは、Xray 自身のトランスポートを直接送信し、再び自分自身に戻さないようにします。

実装の詳細は[アーキテクチャ](/ja/docs/developers/architecture)を参照してください。対応するリンク形式とトランスポートは[プロトコル](/ja/docs/reference/protocols)を参照してください。
