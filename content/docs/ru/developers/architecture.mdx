## Один бинарный файл, два режима рабочего стола [#one-binary-two-desktop-modes]

```text
NuggetVPN                  GUI, running as the user
NuggetVPN --core-service   Privileged tunnel service
```

Графический интерфейс запускает другую копию самого себя через процесс авторизации платформы: `osascript` на macOS, `pkexec` на Linux, или UAC на Windows. Таким образом, обе стороны используют одну и ту же версию приложения.

```text
React + Wails UI  ←→  Authenticated socket  ←→  Core service
    user                  JSON lines              admin
                                              TUN, DNS, routing
                                              embedded engines
```

Привилегированный сервис вызывает основные библиотеки в процессе. Журналы, состояние соединения, счетчики байтов и список активных соединений возвращаются через тот же сокет. Закрытие графического интерфейса завершает работу службы; служба также отслеживает процесс GUI, чтобы сбой не оставил службу с удерживаемой таблицей маршрутизации.

## Аутентификация сокета [#socket-authentication]

Каждое соединение службы должно сначала предъявить 256-битный токен на сессию. GUI записывает его в файл `0600`, привилегированный процесс читает и удаляет файл, а неаутентифицированные соединения закрываются без раскрытия состояния.

Передача токена через файл позволяет избежать его публикации в общедоступной командной строке на Linux. Явная аутентификация также покрывает платформы, где chmod и chown Unix-сокета не обеспечивают ожидаемую границу доступа.

## Встроенные движки [#embedded-engines]

Встроенный форк TodayCore сохраняет путь модуля sing-box с помощью директивы Go `replace`. Официальные sing-box и sing-tun включены под отдельными путями модулей в `third_party/`, чтобы обе реализации могли сосуществовать.

mihomo обрабатывает полные конфигурации Clash. Xray запускает серверную сторону соединения за встроенным ядром, которое сохраняет TUN, DNS и маршрутизацию. Защищенная точка входа loopback напрямую передает транспорт Xray, чтобы избежать самонаправления.

Контроллер ядра HTTP не запущен. Учёт трафика и проверка соединений производятся в процессе, а параметры контроллера из импортированных конфигураций Clash удаляются.

## Карта исходников [#source-map]

| Путь | Обязанности |
| --- | --- |
| `main.go` | Точка входа, GUI/диспетчер сервисов, окно и системный трей. |
| `internal/app/` | Сервисы, доступные для фронтенда. |
| `internal/core/` | Привилегированный сервис, клиент IPC и процессы выполнения в процессе. |
| `internal/sbconfig/` | Профиль и настройки для конфигурации sing-box; компиляция маршрутизации. |
| `internal/cores/` | Перевод конфигураций mihomo и Xray. |
| `internal/link/` | Поделиться ссылкой, разбор JSON sing-box и YAML Clash. |
| `internal/remote/` | Подписки и опциональная синхронизация профиля. |
| `internal/probe/` | Проверка задержки и соединения. |
| `internal/stats/`, `internal/speedtest/` | Сохранённые измерения и тесты скорости. |
| `internal/plugins/` | Упаковка плагинов, проверка, обслуживание и политика песочницы. |
| `internal/cli/` | Командная строка для настольного компьютера и управляющий сокет. |
| `internal/storage/`, `internal/models/` | Постоянство и общие типы. |
| `frontend/` | Приложение React, мост бэкенда и переводы. |
| `Taskfile.yml`, `build/` | Задачи сборки и упаковки. |

## Android граница [#android-boundary]

Поставки VpnService Android обеспечивают туннель, а не привилегированный процесс рабочего стола. `internal/android` передаёт интерфейс sing-box, держит основные сокеты вне VPN и сообщает текущую сеть. Небольшой Java-хост загружает общую библиотеку Go в приложение WebView.

Смотрите [строительство](/ru/docs/developers/building) для запуска проекта и [безопасность плагина](/ru/docs/plugins/security) для границы расширения.
