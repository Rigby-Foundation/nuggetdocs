Скачивайте сборки с [официальных GitHubрелизов](https://github.com/Rigby-Foundation/NuggetVPN/releases). Используйте пакет для вашей операционной системы и процессора.

## Установка на настольный компьютер [#desktop-installation]

<Tabs items={['Windows', 'macOS', 'Linux']}>
<Tab value="Windows">
Скачайте установщик NSIS из Releases и запустите его. Windows использует WebView2 для отображения приложения.

Для автоматической установки выполните это в PowerShell:

```powershell
irm https://raw.githubusercontent.com/Rigby-Foundation/NuggetVPN/main/scripts/install.ps1 | iex
```

Скрипт скачивает последнюю версию, проверяет SHA-256 хеш, опубликованный GitHub, устанавливает её и запускает приложение. Запуск снова обновляет установку.

Для безнадзорной установки используйте релиз с расширением `-silent-installer.exe` или передайте `/S` обычному установщику.
</Tab>
<Tab value="macOS">
Скачайте `.dmg` из Releases и переместите **NuggetVPN** в **Приложения** . Выберите Apple silicon или Intel для вашего Mac, или универсальную сборку, если она предоставлена.

Вы также можете использовать скрипт установщика:

```bash
curl -fsSL https://raw.githubusercontent.com/Rigby-Foundation/NuggetVPN/main/scripts/install.sh | sh
```

Скрипт скачивает и проверяет релиз перед установкой и запуском. Повторный запуск обновляет приложение.

Если macOS сообщает, что приложение повреждено, смотрите [Устранение неполадок Gatekeeper](/ru/docs/troubleshooting#macos-says-the-app-is-damaged).
</Tab>
<Tab value="Linux">
Выберите `.deb`, `.rpm` или `.AppImage` из Releases. Приложение требует GTK 4 и WebKitGTK 6 во время выполнения, а также `pkexec` polkit для повышения прав на рабочем столе.

Скрипт установщика выбирает `.deb` или `.rpm`, если доступны apt, dnf или zypper, и AppImage в противном случае:

```bash
curl -fsSL https://raw.githubusercontent.com/Rigby-Foundation/NuggetVPN/main/scripts/install.sh | sh
```

Он проверяет дайджест версии, устанавливает приложение и запускает его. Повторный запуск обновляет вашу установку.

Для вручную загруженного AppImage сделайте его исполняемым перед открытием:

```bash
chmod +x ./NuggetVPN*.AppImage
```
</Tab>
</Tabs>

## Первый запуск [#first-launch]

Откройте приложение от имени обычного пользователя. На настольных компьютерах первое подключение в каждой сессии приложения требует доступа администратора для создания сетевого интерфейса TUN. Графический интерфейс продолжает работать от имени вашего пользователя; туннель работает в отдельной привилегированной службе.

Приложению необходима конфигурация сервера. Продолжите с [вашим первым подключением](/ru/docs/getting-started/first-connection).

## Обновления [#updates]

Сборки для настольных ПК могут проверять наличие обновлений и устанавливать их внутри приложения. Вы также можете повторно запустить скрипт установки или вручную установить более новую версию. Сохраните [резервную копию](/ru/docs/guides/backups) перед переносом установки на другой компьютер.

Для Android APK и неподписанного iOS IPA следуйте [руководству для мобильных устройств](/ru/docs/getting-started/mobile).
