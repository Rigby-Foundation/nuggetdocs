## Android [#android]

Скачайте APK для вашего устройства с [Releases](https://github.com/Rigby-Foundation/NuggetVPN/releases). Android может попросить разрешить установку из приложения, используемого для открытия APK.

1. Установите и откройте NuggetVPN.
2. Добавьте подписку или сервер с помощью [быстрого старта](/ru/docs/getting-started/first-connection).
3. Подключитесь и одобрите Android VPN запрос разрешений.

Android **VpnService** обеспечивает туннель. Приложение запускает ядро внутри приложения вместо запуска службы администратора на рабочем столе.

### Доступно на Android [#available-on-android]

- Встроенное ядро и Xray.
- Импорт подписок и серверов, включая сканирование QR камерой.
- Маршрутизация, темы, шрифты и маршрутизация контента из плагинов.
- Material You цвета обоев для темы **Системная тема** на Android 12 и новее.

### Функции рабочего стола недоступны на Android [#desktop-features-not-available-on-android]

Официальные sing-box и mihomo недоступны. Правила Wi-Fi, автозапуск при входе, глобальное сочетание клавиш, системный трей, командная строка и обновления внутри приложения также недоступны. Установите более новый APK для обновления.

Страницы плагинов не работают на Android. Нативный мост WebView нельзя изолировать от этих фреймов, поэтому включены только контентные вкладки.

## iOS [#ios]

NuggetVPN не распространяется через App Store. Выпуски предоставляют неподписанный файл, оканчивающийся на `-ios-unsigned.ipa` для iOS 15 и новее.

<Callout type="warn" title="Требуются права VPN">
Подпишите IPA своим собственным сертификатом, используя приложение для подписи или поддерживаемый метод установки, такой как TrollStore. Сертификат для подписи должен разрешать Network Extensions и пакетный туннель. Бесплатный сертификат Apple ID не предоставляет эти возможности: приложение можно установить, но оно не сможет подключиться.
</Callout>

После установки правильно подписанной сборки импортируйте конфигурацию вашего провайдера и примите системный запрос VPN при подключении. Следуйте возможностям установленной сборки iOS; элементы управления только для настольной версии и список функций Android не следует предполагать применимыми к iOS.

## Перенос вашей конфигурации [#moving-your-configuration]

Подписку провайдера можно импортировать на каждом устройстве. Рассматривайте её URL как учетные данные. Для поведения резервного копирования и восстановления см. [backups](/ru/docs/guides/backups).
