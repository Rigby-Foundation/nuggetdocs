Эти элементы управления применяются к рабочему столу. Android не предоставляет правила Wi-Fi, глобальный ярлык, запуск при входе в систему или командную строку.

## Глобальный ярлык [#global-shortcut]

Установите комбинацию клавиш в **Настройки → Поведение → Сочетание клавиш** . Она подключает или отключает даже когда окно скрыто, используя последний выбранный сервер.

Используйте управление очисткой, чтобы удалить ярлык. Выберите комбинацию, которая не конфликтует с другим приложением.

## Правила Wi-Fi [#wi-fi-rules]

Откройте **Настройки → Wi-Fi** для управления доверенными именами сетей.

- **Подключаться в недоверенных сетях** подключается к последнему использованному серверу, когда вы подключаетесь к Wi-Fi сети, которой не доверяете.
- **Отключаться в доверенных сетях** отключается, когда вы подключаетесь к надежной сети.

Используйте **Доверять** для текущей сети или добавьте имя в список доверенных вручную. Надежная сеть — это сеть, в которой вы решили, что «VPN» не требуется; её имя не является гарантией безопасности.

### Если имя сети скрыто [#if-the-network-name-is-hidden]

Некоторые операционные системы требуют разрешения на определение местоположения для отображения имени Wi-Fi. Разрешите приложению считывать его в настройках конфиденциальности системы или введите имена доверенных сетей самостоятельно. Приложение сообщает, когда определение Wi-Fi не поддерживается.

## Терминал и скрипты [#terminal-and-scripts]

Командная строка [управляет уже запущенным экземпляром рабочего стола](/ru/docs/reference/cli):

```bash
NuggetVPN status
NuggetVPN connect Tokyo
NuggetVPN setup Work
NuggetVPN disconnect
```

Добавьте `--json` для структурированных результатов и используйте коды выхода для обнаружения сбоев. Приложение можно свернуть в трей, но оно должно продолжать работать.

Для изменений маршрутизации по времени используйте [расписания маршрутизации](/ru/docs/guides/routing-setups#schedule-a-setup).
