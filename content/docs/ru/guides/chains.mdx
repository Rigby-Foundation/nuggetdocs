---
title: "Цепочки прокси"
description: "Пропускайте через промежуточные профили перед достижением вашего выходного сервера."
---

Цепочка прокси отправляет трафик через каждый настроенный промежуточный узел по порядку перед выбранным выходом. Каждый узел соединяется через предыдущий.

```text
Your device → First hop → Second hop → Selected exit → Destination
```

## Построить цепочку [#build-a-chain]

1. Добавьте необходимые профили в **Профили и подписки** .
2. Выберите профиль, который должен быть конечным выходом.
3. Откройте **Настройки → Цепочка прокси** и включите **Цепочка через другие профили** .
4. Добавьте промежуточные профили в порядке. Первое звено ближе всего к вам; последнее звено идет непосредственно перед выходом.
5. Подключитесь и проверьте активное соединение.

Используйте кнопки перемещения вверх и вниз для изменения порядка звеньев. Удалите звено, чтобы исключить его из цепочки. Выбранный выход и профили, уже находящиеся в цепочке, исключены из выбора добавления звена.

## Диагностировать цепочку [#diagnose-a-chain]

Каждое звено должно быть доступным и поддерживаться выбранным ядром. Если соединение не удается, сначала проверьте выход отдельно, затем добавляйте по одному промежуточному звену.

Большее количество прыжков создаёт больше соединений и потенциальных точек отказа. Используйте [тест скорости и журналы](/ru/docs/guides/monitoring), чтобы сравнить поведение, и проверьте [поддержку ядра](/ru/docs/reference/cores) для каждого используемого протокола.
