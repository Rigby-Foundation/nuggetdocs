**профиль** описывает подключение. **подписка** — это URL, который предоставляет коллекцию серверов и может быть обновлён, когда провайдер их изменяет.

## Добавить источник [#add-a-source]

Откройте **Профили и подписки → Добавить** и вставьте свою информацию для подключения.

| Ввод | Что происходит |
| --- | --- |
| URL подписки HTTP или HTTPS | Загружает подписку провайдера. |
| Ссылка для совместного использования протокола | Создает индивидуальный профиль. |
| JSON sing-box | Импортирует конфигурацию. |
| Конфигурация Clash | Принята парсером конфигурации; используйте mihomo, когда нужно запустить полную конфигурацию Clash по предоставленным данным. |
| QR-изображение | Декодирует содержимое в диалог добавления для просмотра. |

Диалог добавления рекламирует URL подписок, ссылки на серверы и sing-box JSON. Если формат или протокол не работают, сравните его с [справочником протоколов](/ru/docs/reference/protocols) и [основными ограничениями](/ru/docs/reference/cores).

## Обновить подписку [#refresh-a-subscription]

Используйте элемент управления обновлением на её карточке в **Профили и подписки** . Это получает текущий список серверов с исходного URL провайдера.

В разделе **Настройки → Поведение** , **Обновлять подписки автоматически** включает обновление при запуске и каждые шесть часов. Провайдер также может предложить интервал обновления, который вы можете принять. Отключение автоматического обновления подписок выключает автоматическое обновление для всех подписок; ручное обновление остаётся доступным.

## Использование, срок действия и сообщения от провайдера [#usage-expiry-and-provider-messages]

NuggetVPN показывает данные по лимиту подписки, использованию и сроку действия только в том случае, если провайдер включает их в свой ответ. Отсутствие значений не означает, что у подписки безлимитный трафик или нет срока действия.

Провайдеры также могут предоставлять заголовок, брендинг и объявления. Они описывают подписку; они отличаются от локально измеряемых счётчиков трафика приложения.

## Идентификатор подписки [#subscription-identity]

Некоторые провайдеры ограничивают, какие клиенты или устройства могут получать подписку. **Настройки → Идентификация клиента** управляет идентификатором клиента и ID устройства, используемыми для этих запросов. Если в противном случае действительная подписка отклоняется, проверьте требования вашего провайдера перед изменением этих значений.

## Поделиться, экспортировать и удалить [#share-export-and-delete]

Управления источниками и прокси предлагают функции совместного использования и экспорта. Список источников также поддерживает выбор нескольких записей для обновления, копирования, экспорта или удаления.

URL подписки, ссылка на сервер, QR-код или экспортированная конфигурация могут содержать учетные данные. Делитесь ими только с теми, кто должен иметь возможность использовать это соединение.

Удаление источника удаляет его из этой установки. Чтобы сохранить полную конфигурацию, сначала [сохраните резервную копию](/ru/docs/guides/backups).
