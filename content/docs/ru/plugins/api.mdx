Страницы вызывают методы с помощью `nugget.call(method, params)` и слушают события с помощью `nugget.on(event, handler)`; см. [написание страниц](/ru/docs/plugins/pages).

Если у плагина нет нужного разрешения, вызов метода завершается ошибкой с указанием недостающего разрешения. Вызовы методов выключенного плагина тоже отклоняются.

## Методы [#methods]

### Приложение [#app]

| Метод | Разрешение | Параметры | Возвращает |
| --- | --- | --- | --- |
| `app.info` | — | | `{ version, language, platform, plugin: { id, version, permissions } }` |
| `app.theme` | — | | Тема, которую применяет SDK; см. [ниже](#apptheme). |
| `ui.toast` | — | `{ text, kind? }` | `null`. Показывает короткое сообщение с префиксом имени плагина. `kind` это `"info"` (по умолчанию), `"success"` или `"error"`. Не более одного сообщения каждые 1,5 секунды. |
| `storage.get` | — | `{ key }` | Сохранённое значение JSON или `null`. |
| `storage.set` | — | `{ key, value }` | `null`. `value` может быть любым значением JSON; `null` удаляет ключ. Размер ключей до 200 символов, а общий объём до 1 МБ. |
| `notify` | `notifications` | `{ title, body }` | `null`. Системное уведомление с заголовком "Название плагина: заголовок". Не чаще одного раза каждые 10 секунд. Пользователь может отключить уведомления. |

### Соединение [#connection]

| Метод | Разрешение | Параметры | Возвращает |
| --- | --- | --- | --- |
| `vpn.status` | `state` | | Объект [состояния](#state). |
| `vpn.traffic` | `state` | | [Образец данных о трафике](#traffic). |
| `vpn.connect` | `control` | `{ server? }` | Объект [состояния](#state). Подключает к серверу с идентификатором из `servers.list` или к выбранному в приложении. Promise выполняется после подключения и отклоняется, если ни один сервер не заработал. |
| `vpn.disconnect` | `control` | | `null` |
| `connections.list` | `connections` | | Открытые соединения; см. [ниже](#connection). |

### Серверы и маршрутизация [#servers-and-routing]

| Метод | Разрешение | Параметры | Возвращает |
| --- | --- | --- | --- |
| `servers.list` | `profiles` | | `[{ id, name, protocol, host, favorite, subscription }]`. `subscription` — это домен подписки, или `null`. Никогда не ссылки, которые содержат учетные данные. |
| `servers.add` | `import` | `{ link, name? }` | `null`. Добавляет сервер из общей ссылки (`vless://`, `ss://`, …). |
| `subscriptions.add` | `import` | `{ url }` | `null`. Добавляет и получает подписку. |
| `routing.addRule` | `routing` | `{ kind, values, action, invert? }` | `null`. Добавляет правило в конец маршрута пользователя, с примечанием, что ваше расширение его добавило, и применяет его. |

`routing.addRule`:

| Параметр | |
| --- | --- |
| `kind` | `apps` (имена программ), `domains`, `ip` (адреса и диапазоны CIDR), `domain_regex`, `port` (числа и диапазоны вроде `8000-8080`), `protocol` (`bittorrent`, `quic`, …), `geosite`, `geoip` (коды стран вроде `ru`), `network` (`tcp`, `udp`), `ruleset` (URL списков правил). |
| `values` | Значения для сопоставления, до 5000. |
| `action` | `proxy` (через VPN), `direct` или `block`. |
| `invert` | Сопоставлять всё, что не подходит под значения. |

## События [#events]

| Событие | Разрешение | Данные |
| --- | --- | --- |
| `vpn.state` | `state` | Объект [состояния](#state): отправляется при подписке, а затем при каждом изменении. |
| `vpn.traffic` | `state` | [Данные о трафике](#traffic), раз в секунду во время подключения. |
| `app.theme` | — | [Тема](#apptheme) при каждом её изменении пользователем. SDK применяет её автоматически. |

## Типы [#types]

### Государство [#state]

```json
{
  "status": "connected",
  "server": "Frankfurt 1",
  "server_id": "p-de",
  "since": 1790000000000,
  "reconnecting": false,
  "blocked": false,
  "error": null
}
```

| Поле | |
| --- | --- |
| `status` | `idle`, `connecting`, `connected` или `error`. |
| `server`, `server_id` | Сервер, при подключении или подключённый. |
| `since` | Когда туннель появился, в миллисекундах Unix. |
| `reconnecting` | Туннель опустился и возвращается обратно. |
| `blocked` | Аварийный выключатель блокирует весь трафик. |
| `error` | Что пошло не так, когда `status` является `error`. |

### Движение [#traffic]

```json
{ "up": 12000000, "down": 340000000, "up_rate": 42000, "down_rate": 1830000, "total_up": 0, "total_down": 0 }
```

`up` и `down` — это байты за эту сессию; показатели указаны в байтах в секунду.

### Соединение [#connection-1]

```json
{
  "id": "…",
  "network": "tcp",
  "protocol": "tls",
  "host": "www.example.com",
  "destination": "93.184.216.34:443",
  "app": "chrome.exe",
  "rule": "rule-1",
  "route": "proxy",
  "server": "p-de",
  "upload": 1200,
  "download": 48000,
  "started": 1790000000000
}
```

`rule` — это идентификатор правила маршрутизации, которое совпало, `"__default"` — для всего остального, или `""` — для соединений, которые приложение маршрутизирует самостоятельно.

### app.theme [#apptheme]

```json
{
  "mode": "dark",
  "colors": { "background": "oklch(…)", "foreground": "…", "primary": "…" },
  "radius": "0.625rem",
  "font": "…",
  "language": "en",
  "dir": "ltr"
}
```

## Протокол низкого уровня [#low-level-protocol]

SDK оборачивает `postMessage`. Вам это не нужно, если вы не пишете собственный SDK:

- **Страница к приложению:**
  - `{ nugget: 1, id, method, params }`: вызов;
  - `{ nugget: 1, subscribe: "event" }`: прослушивание события;
  - `{ nugget: 1, hello: true }`: страница загружена;
  - `{ nugget: 1, height }`: высота панели.
- **Приложение к странице:**
  - `{ nugget: 1, id, result }` или `{ nugget: 1, id, error }`: ответ;
  - `{ nugget: 1, event, data }`: событие.
