Контент не требует кода и разрешений: плагин может состоять только из `plugin.json` и нескольких файлов.

## Темы [#themes]

Темы используют те же номера, что и редактор тем в Настройки → Внешний вид. Самый простой способ найти подходящие значения — сначала создать тему там, а затем скопировать её номера.

```json
"themes": [
  {
    "id": "storm",
    "name": "Storm",
    "mode": "dark",
    "background": { "h": 250, "c": 0.03, "l": 0.14 },
    "accent": { "h": 190, "c": 0.13 },
    "image": {
      "file": "images/storm.jpg",
      "blur": 12,
      "brightness": 0.9,
      "saturate": 1,
      "dim": 0.35,
      "panel": 0.65
    }
  }
]
```

| Поле | |
| --- | --- |
| `id` | Уникально внутри плагина, в той же форме, что и идентификатор плагина. |
| `name` | До 60 символов, показывается в выборе темы. |
| `mode` | `"dark"` или `"light"`. |
| `background.h` | Оттенок страницы, 0–360. |
| `background.c` | Тон, 0–0.08. 0 — серый. |
| `background.l` | Светлота: 0–0.3 для тёмных тем, 0.9–1 для светлых. |
| `accent.h` | Оттенок кнопок, переключателей и выделений, 0–360. |
| `accent.c` | Яркость акцента, 0–0.25. |
| `image` | Необязательно: изображение за приложением. |
| `image.file` | PNG, JPEG, WebP или GIF в плагине. |
| `image.blur` | Размытие в пикселях, 0–40. |
| `image.brightness` | 0.3–1.5; 1 оставляет как есть. |
| `image.saturate` | 0–2; 0 — черно-белое. |
| `image.dim` | Насколько фон темы перекрывает его, 0–0.9. |
| `image.panel` | Насколько непрозрачны панели приложения поверх него, 0.2 (стеклянные) до 1 (сплошные). |

Значения за пределами их диапазона зажимаются, а не отклоняются. Цвета находятся в OKLCH, а светлота акцента фиксирована для каждого режима, поэтому текст на кнопках всегда остаётся читаемым.

## Шрифты [#fonts]

```json
"fonts": [
  { "name": "Weather Sans", "file": "fonts/weather-sans.woff2" }
]
```

TTF, OTF, WOFF или WOFF2. Каждый шрифт отображается в списке шрифтов под своим именем и предлагается для любого языка. Буквы, которых не хватает, берутся из запасных шрифтов.

Проверьте, что лицензия шрифта позволяет его перепродавать.

## Настройки маршрутизации [#routing-setups]

```json
"routing": [
  {
    "name": "Streaming direct",
    "description": "Netflix, YouTube and Twitch outside the VPN.",
    "file": "routing/streaming.vflow"
  }
]
```

Файл `.vflow` — это целый граф маршрутизации, тот самый файл, который сохраняется через Routing → Export. Создайте настройку в приложении, экспортируйте её и поместите файл в ваш плагин. Использование файла из Routing → From plugins заменяет маршрутизацию пользователя; пользователь может отменить это.

Настройки, которые ссылаются на конкретные серверы, теряют эти ссылки на чужом компьютере, поскольку их серверы отличаются. Правила, которые отправляют трафик "через VPN", "прямо" или "блокировать", работают везде.
