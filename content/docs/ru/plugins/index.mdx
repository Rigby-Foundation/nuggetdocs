<Callout title="Ограничение Android">
Страницы плагинов не работают на Android. Темы, шрифты и схемы маршрутизации поддерживаются.
</Callout>

Плагин — это один файл `.nuggetplugin`: zip-архив с `plugin.json` в его корне. Он может включать:

| | Где отображается |
| --- | --- |
| **Темы** | Настройки → Внешний вид → Тема, в разделе "Из плагинов" |
| **Шрифты** | Список шрифтов в Настройки → Внешний вид |
| **Схемы маршрутизации** | Маршрутизация → Из плагинов |
| **Страница** | В настройках плагина, в Настройки → Плагины |
| **Фоновая страница** | Никуда: она работает незаметно, пока плагин включен |

Плагин с только темами, шрифтами и настройками маршрутизации вообще не выполняет код. Страницы представляют собой обычный HTML и JavaScript. Они работают в песочнице и взаимодействуют с приложением через небольшое сообщение API, и только по разрешению пользователя при установке.

## Быстрый старт [#quick-start]

Самый быстрый старт — это пример в [`examples/plugins/glance`](https://github.com/Rigby-Foundation/NuggetVPN/tree/main/examples/plugins/glance). В нем есть карточка состояния с кнопкой подключения, тема и настройка маршрутизации, которая блокирует распространенные трекеры:

```
glance/
├── plugin.json
├── icon.svg
├── panel.html
└── routing/
    └── trackers.vflow
```

Скопируйте его, измените `id` в `plugin.json` на свой собственный и соберите его:

```bash
go run ./cmd/nuggetplugin path/to/your-plugin
```

Это записывает `your-plugin.nuggetplugin` рядом с папкой. Оно проверяет плагин так же, как приложение при установке, поэтому любая ошибка сначала появится здесь. Затем установите его через **Настройки → Плагины → Установить плагин…** .

Минимальный плагин, который добавляет только тему:

```json
{
  "format": 1,
  "id": "com.example.dusk",
  "name": "Dusk",
  "version": "1.0.0",
  "themes": [
    {
      "id": "dusk",
      "name": "Dusk",
      "mode": "dark",
      "background": { "h": 280, "c": 0.03, "l": 0.16 },
      "accent": { "h": 30, "c": 0.15 }
    }
  ]
}
```
