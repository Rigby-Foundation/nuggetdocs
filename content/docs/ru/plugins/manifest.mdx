У каждого плагина есть `plugin.json` в корне его zip.

```json
{
  "format": 1,
  "id": "com.example.weather",
  "name": "Server weather",
  "version": "1.0.0",
  "author": "You",
  "description": "What it does, in a sentence or two.",
  "homepage": "https://example.com/weather",
  "icon": "icon.png",

  "themes": [ … ],
  "fonts": [ … ],
  "routing": [ … ],

  "panel": { "title": "Weather", "file": "panel.html" },
  "background": "background.html",

  "permissions": ["state", "profiles", "notifications"],
  "network": ["status.example.com"]
}
```

## О плагине [#about-the-plugin]

| Поле | Обязательно | |
| --- | --- | --- |
| `format` | да | Всегда `1`. Более новая версия приложения может читать новые форматы; это приложение отказывается от других и сообщает об этом. |
| `id` | да | Постоянный идентификатор вашего плагина. Используйте 3–64 строчные буквы, цифры, `.`, `-` и `_`, начиная и заканчивая буквой или цифрой. Хорошо подходит обратный домен: `com.example.weather`. Обновление должно сохранять тот же идентификатор. |
| `name` | да | До 60 символов. |
| `version` | да | Любая строка версии, состоящая из букв, цифр, `.`, `+` и `-`, до 32 символов. Отображается пользователю; приложение не сравнивает версии. |
| `author` | | До 80 символов. |
| `description` | | До 500 символов, отображаемых в запросе установки и в списке плагинов. |
| `homepage` | | Адрес `https://`. Отображается, но никогда не открывается приложением. |
| `icon` | | Файл PNG, JPEG, WebP или SVG в плагине. Отображается квадратным, размер 36–40 px. |

## Контент [#content]

| Поле | |
| --- | --- |
| `themes` | Пользовательские темы. См. [content](/ru/docs/plugins/content#themes). |
| `fonts` | Файлы шрифтов. См. [content](/ru/docs/plugins/content#fonts). |
| `routing` | Настройки маршрутизации `.vflow`. См. [content](/ru/docs/plugins/content#routing-setups). |

## Страницы [#pages]

| Поле | |
| --- | --- |
| `panel` | `{ "title": "…", "file": "panel.html" }`: страница, отображаемая в разделе плагинов в Настройках → Плагины. `title` имеет до 40 символов и по умолчанию соответствует имени плагина. |
| `background` | `"background.html"`: страница продолжает работать, пока плагин включен. |

См. [создание страниц](/ru/docs/plugins/pages).

## Доступ [#access]

| Поле | |
| --- | --- |
| `permissions` | Что могут делать страницы плагина. См. [разрешения](/ru/docs/plugins/security#permissions). Запрашивайте только то, что используете; при установке отображается полный список. |
| `network` | Имена хостов, с которыми ваши страницы могут связываться, через `https` и `wss`, например `api.example.com` или `*.example.com`. Доступ к чему-либо ещё невозможен. IP-адреса, `localhost` и локальные имена (`.local`, `.lan`, `.internal`, `.home.arpa`) запрещены. Разрешено только для плагинов с страницей. |

## Файлы [#files]

Имена файлов могут использовать буквы, цифры, `.`, `-` и `_`, в папках, разделённых `/`. Имена не могут начинаться с точки. Каждый файл, указанный в манифесте, должен быть в плагине с правильным типом расширения.

Плагин может быть размером не более 50 МБ, содержать максимум 500 файлов размером до 25 МБ каждый и 80 МБ в распакованном виде.

Файлы обслуживаются с типом, определяемым расширением. Всё остальное не обслуживается:

`.html`, `.js`, `.mjs`, `.css`, `.json`, `.svg`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.ttf`, `.otf`, `.woff`, `.woff2`, `.txt`
