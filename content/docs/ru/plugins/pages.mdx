У плагина может быть две страницы, обе обычный HTML:

- панель **панель** , показанная под плагином в Настройки → Плагины;
- фоновая **фоновая страница** , которая продолжает работать незаметно, пока плагин включен. Используйте её, чтобы реагировать на события, например, на уведомление при потере соединения.

## SDK [#the-sdk]

Включите SDK и используйте глобальный `nugget`:

```html
<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <script src="/plugins/_sdk/nugget.js"></script>
</head>
<body>
  <p id="status">…</p>
  <script>
    const show = (state) => {
      document.getElementById("status").textContent = state.status;
    };
    nugget.call("vpn.status").then(show);
    nugget.on("vpn.state", show);
  </script>
</body>
</html>
```

| | |
| --- | --- |
| `nugget.call(method, params?)` | Вызывает метод приложения. Возвращает обещание с результатом или отклоняется с `Error`, сообщение которого указывает, что пошло не так. |
| `nugget.on(event, handler)` | Слушает событие. Возвращает функцию, которая прекращает прослушивание. |
| `nugget.fit()` | Просит приложение изменить размер панели под её содержимое. SDK уже делает это всякий раз, когда изменяется размер страницы. |

Каждый метод и событие находятся в справочнике [API](/ru/docs/plugins/api).

## Похоже на приложение [#looking-like-the-app]

SDK украшает страницу темой пользователя и поддерживает её актуальной:

- **Цвета:** установлены как CSS-переменные на `<html>`:
  - `--background`, `--foreground`, `--card`, `--card-foreground`;
  - `--primary`, `--primary-foreground`, `--secondary`, `--muted`,
 `--muted-foreground`, `--accent`;
  - `--border`, `--input`, `--ring`, `--destructive`;
  - `--status-connected`, `--status-connecting`, `--status-error`,
 `--status-idle`.
- **Форма:** `--radius`, радиус углов приложения.
- **Атрибуты:** `color-scheme`, `data-theme="light|dark"`, `lang` и
 `dir` (персидский читается справа налево).

Оставьте фон страницы прозрачным, и она будет выглядеть как часть приложения:

```css
html { background: transparent; color: var(--foreground); font: 13px/1.4 system-ui, sans-serif; }
button { background: var(--primary); color: var(--primary-foreground); border: 0; border-radius: var(--radius); }
.muted { color: var(--muted-foreground); }
```

Шрифты самого приложения недоступны внутри страницы; используйте системный стек шрифтов или подключите шрифт через плагин.

## Размер [#size]

Панель имеет такую же ширину, как и карточка плагина, и подстраивается под своё содержимое, её высота варьируется от 60 до 4000 пикселей. Избегайте `height: 100vh` раскладок: рамка принимает высоту того, что в ней находится.

## Хранение данных [#storing-things]

Каждый плагин имеет своё собственное хранилище до 1 МБ в формате JSON, сохраняемое при перезапуске и обновлениях, и удаляемое при удалении плагина:

```js
const count = (await nugget.call("storage.get", { key: "count" })) ?? 0;
await nugget.call("storage.set", { key: "count", value: count + 1 });
```

`localStorage` и куки не работают в песочнице.

## Что не работает [#what-doesnt-work]

Страницы работают в песочнице; см. [разрешения и песочница](/ru/docs/plugins/security). Вкратце:

- нет форм (используйте JavaScript и `nugget.call`);
- нет всплывающих окон, `alert` или новых окон;
- нет вложенных фреймов;
- нет `eval` или `new Function`;
- сеть недоступна, кроме хостов в `network`;
- никакие скрипты, стили или картинки не должны использоваться, кроме тех, что принадлежат вашему плагину.

Ссылки на собственные файлы вашего плагина работают с абсолютными путями,
`/plugins/<your id>/file.png`, или относительными.

## Отладка [#debugging]

В версии для разработки (`make dev`) зажмите Shift и кликните правой кнопкой мыши на страницу, затем выберите
«Инспектировать», чтобы открыть инструменты разработчика, после чего выберите фрейм вашего плагина в
селекторе контекста консоли. Вывод `console.log` появляется там.
