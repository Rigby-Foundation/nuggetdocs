## Сборка [#building]

```bash
go run ./cmd/nuggetplugin path/to/your-plugin
go run ./cmd/nuggetplugin path/to/your-plugin out/your-plugin.nuggetplugin
```

Первый вариант записывает `your-plugin.nuggetplugin` рядом с папкой; второй
задает имя выходного файла. В любом случае проверка плагина происходит так, как если бы он был установлен,
и выводит запрошенные данные:

```
Glance 1.0.0: examples/plugins/glance.nuggetplugin (3 KB)
asks for: state, control
```

`.nuggetplugin` — это обычный zip-файл, поэтому любой zip-инструмент тоже подходит, при условии, что `plugin.json` находится в корне, а не внутри папки. `nuggetplugin` все еще является способом убедиться, что установка прошла успешно.

## Версии и обновления [#versions-and-updates]

Установка плагина с тем же `id`, что и уже установленный, обновляет его:

- его файлы заменяются;
- его хранилище сохраняется;
- если новая версия запрашивает разрешения, которых не было у старой, окно установки отмечает их, и пользователю нужно снова их разрешить.

Приложение не сравнивает версии, поэтому установка более старой версии тоже работает. Меняйте `version` для каждого выпуска, чтобы пользователи могли определить, какая версия у них установлена.

Никогда не меняйте `id`: плагин с новым идентификатором — это другой плагин, без сохранений старого.

## Обмен [#sharing]

Разместите файл `.nuggetplugin` там, где люди могут его скачать: на GitHub релизе, на вашем сайте, в чате. Плагины устанавливаются из файла, и приложение никогда не загружает их самостоятельно.

В описании или на главной странице вашего плагина укажите:
- что он делает;
- почему ему нужны каждое запрашиваемое разрешение;
- с какими хостами он связывается и что туда отправляет.

## Контрольный список [#checklist]

- [ ] `id` ваш и постоянный.
- [ ] `version` обновлён.
- [ ] Только те разрешения, которые вы используете.
- [ ] `network` перечисляет только те хосты, с которыми вы связываетесь.
- [ ] Страница выглядит правильно как в светлой, так и в тёмной теме, а также на языках с письмом справа налево.
- [ ] Шрифты и изображения разрешено распространять.
- [ ] `go run ./cmd/nuggetplugin` проходит проверку.
