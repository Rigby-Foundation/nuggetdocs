Собственная программа приложения также работает как команда: она управляет копией, которая
запущена, из терминала, скрипта или клавиатурного ярлыка.

```
NuggetVPN status
NuggetVPN connect Tokyo
NuggetVPN disconnect
```

Приложение должно быть запущено (оно может быть свернуто в трей). Если приложение
не запущено, команды сообщают об этом и завершаются с кодом 2.

## Команды [#commands]

| Команда | |
| --- | --- |
| `status` | Включен ли VPN, через какой сервер, как долго и какой трафик. |
| `connect [server]` | Подключается. К серверу по его идентификатору, точному имени или части имени, соответствующей только одному серверу. Без указания — к последнему использованному серверу. |
| `disconnect` | Отключается. |
| `servers [search]` | Показывает список серверов, текущий отмечен `*`, опционально только те, чьи имена содержат `search`. |
| `setup [name]` | Показывает настройки маршрутизации, активная отмечена `*`, или переключается на одну по имени. |
| `speedtest` | Выполняет тест скорости через текущий сервер и выводит загрузку, выгрузку, пинг и джиттер. |
| `help` | Показывает список команд. |

Добавьте `--json` к любой команде, чтобы получить JSON вместо текста, для скриптов:

```
$ NuggetVPN status --json
{"status":"connected","profile_id":"p-de","profile":"Frankfurt 1","since":1790000000000}
```

## Коды выхода [#exit-codes]

| Код | |
| --- | --- |
| 0 | Выполнено. |
| 1 | Приложение отказалось: нет такого сервера, не подключено для теста скорости и так далее. Причина указана. |
| 2 | Приложение не запущено. |

## Где программа [#where-the-program-is]

| Система | |
| --- | --- |
| Windows | `C:\Program Files\Rigby Foundation\NuggetVPN\NuggetVPN.exe`, или где вы его установили |
| macOS | `/Applications/NuggetVPN.app/Contents/MacOS/NuggetVPN` |
| Linux | `/usr/bin/NuggetVPN` из .deb или .rpm, или сам AppImage |

На macOS псевдоним упрощает работу:

```bash
alias nuggetvpn=/Applications/NuggetVPN.app/Contents/MacOS/NuggetVPN
```

### Windows [#windows]

NuggetVPN — это оконная программа, а Windows не ждёт их завершения. В `cmd` приглашение возвращается до появления вывода. В PowerShell, перенаправление вывода заставляет его ждать:

```powershell
& "C:\Program Files\Rigby Foundation\NuggetVPN\NuggetVPN.exe" status | Write-Output
```

Скрипты, которые читают вывод или код завершения, или перенаправляют его, работают как обычно.

## Безопасность [#security]

Запущенное приложение слушает сокет в вашей собственной пользовательской папке, и каждая команда содержит токен из файла, который может читать только ваша учетная запись. Другие учетные записи на том же компьютере не могут его использовать.
