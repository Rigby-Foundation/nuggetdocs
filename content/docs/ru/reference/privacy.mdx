## Приложение и его ядра [#the-app-and-its-cores]

Все прокси-ядерные компоненты скомпилированы в приложение как Go библиотеки. Никакой исполняемый файл ядра не загружается и не запускается во время работы. На настольном компьютере пользовательский интерфейс работает от вашей учётной записи и запускает привилегированную копию того же бинарного файла для создания и управления туннелем.

Сервис ядра аутентифицирует сокет-соединения с использованием токена на сеанс. GUI создаёт токен в ограниченном файле, а повысившийся сервис читает и удаляет его.

## Нет контроллера ядра HTTP [#no-core-http-controller]

Счётчики и списки активных соединений считываются в процессе. Ядра не предоставляют контроллер HTTP. Настройки контроллера, запрашиваемые конфигурацией Clash, удаляются до того, как mihomo запускает её.

Настольный CLI использует отдельный аутентифицированный локальный управляющий сокет для вашей учетной записи. См. [Безопасность CLI](/ru/docs/reference/cli#security).

## Записи и диагностика [#records-and-diagnostics]

- Статистика трафика хранится на вашем компьютере.
- Релизные сборки начинаются с выхода из системы.
- Включение ведения журнала записывает диагностику приложения и ядра на экран и в файл.
- Выключение ведения журнала также удаляет сохранённый журнал.

Просмотрите **Настройки → Конфиденциальность** для текущих настроек и [мониторинг](/ru/docs/guides/monitoring) для диагностических шагов.

## Внешние запросы [#external-requests]

Подписки загружаются с URL-адресов, которые вы добавляете. Автоматическое обновление подписок, измерения сервера, тесты скорости, загрузки списков правил, синхронизация и проверки обновлений выполняют сетевые запросы при использовании. Поставщики получают запросы, необходимые для обслуживания их подписок и соединений.

Эта страница описывает поведение клиента; она не устанавливает политику ведения журналов или конфиденциальности для вашего VPN поставщика.

## Плагины [#plugins]

Плагины запрашивают разрешения при установке. Темы только с контентом, шрифты и настройки маршрутизации не выполняют код. Страницы плагинов выполняются в песочнице и могут вызывать только разрешённые методы приложения или связываться с объявленными сетевыми хостами.

Доступ плагина к списку серверов не включает ссылки на общий доступ с учетными данными. Плагины не могут читать файлы, настройки или логи, выполнять нативный код или работать в привилегированном сервисе. См. [разрешения плагина](/ru/docs/plugins/security) для полного контракта.
