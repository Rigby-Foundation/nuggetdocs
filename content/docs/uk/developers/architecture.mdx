## Один двійковий файл, два режими робочого столу [#one-binary-two-desktop-modes]

```text
NuggetVPN                  GUI, running as the user
NuggetVPN --core-service   Privileged tunnel service
```

Графічний інтерфейс запускає ще одну копію самого себе через потік авторизації платформи: `osascript` на macOS, `pkexec` на Linux або UAC на Windows. Тому обидві сторони використовують одну й ту ж версію додатка.

```text
React + Wails UI  ←→  Authenticated socket  ←→  Core service
    user                  JSON lines              admin
                                              TUN, DNS, routing
                                              embedded engines
```

Привілейований сервіс викликає основні бібліотеки в процесі. Логи, стан підключення, лічильники байтів і список активних підключень повертаються через той самий сокет. Закриття GUI завершує роботу сервісу; сервіс також стежить за процесом GUI, щоб збій не залишив сервіс із таблицею маршрутів.

## Аутентифікація сокета [#socket-authentication]

Кожне підключення до сервісу повинно спершу подати 256-бітний токен на сеанс. GUI записує його у файл `0600`, підвищений процес зчитує і видаляє файл, а неавторизовані підключення закриваються без доступу до стану.

Передача токена через файл уникає його публікації у командному рядку, доступному для всіх на Linux. Явна автентифікація також покриває платформи, де chmod та chown Unix сокетів не забезпечують очікуваних меж доступу.

## Вбудовані рушії [#embedded-engines]

Вбудований форк TodayCore зберігає шлях модуля sing-box за допомогою директиви Go `replace`. Офіційні sing-box та sing-tun включені як залежності під окремими шляхами модулів у `third_party/`, щоб обидві реалізації могли співіснувати.

mihomo обробляє повні конфігурації Clash. Xray запускає серверну частину з’єднання за вбудованим ядром, яке зберігає TUN, DNS та маршрутизацію. Захищена точка входу loopback безпосередньо передає транспорт Xray для уникнення самостійної маршрутизації.

Жоден основний HTTP контролер не запущений. Облік трафіку та перевірка з'єднань зчитуються у процесі, а опції контролера з імпортованих Clash конфігурацій видаляються.

## Карта джерела [#source-map]

| Шлях | Відповідальність |
| --- | --- |
| `main.go` | Точка входу, диспетчер GUI/сервісів, вікно та трей. |
| `internal/app/` | Служби, доступні для фронтенду. |
| `internal/core/` | Привілейована служба, клієнт IPC та runtime у процесі. |
| `internal/sbconfig/` | Профіль та налаштування до sing-box конфігурації; компіляція маршрутизації. |
| `internal/cores/` | Переклад mihomo та Xray конфігурації. |
| `internal/link/` | Поділитися посиланням, sing-box JSON та Clash YAML парсинг. |
| `internal/remote/` | Підписки та необов'язкова синхронізація профілю. |
| `internal/probe/` | Перевірка затримки та підключення. |
| `internal/stats/`, `internal/speedtest/` | Збережені вимірювання та тести швидкості. |
| `internal/plugins/` | Упаковка плагінів, валідація, обслуговування та політика пісочниці. |
| `internal/cli/` | Командний рядок для десктопа та контрольний сокет. |
| `internal/storage/`, `internal/models/` | Стійкість та спільні типи. |
| `frontend/` | React додаток, бекенд-міст та переклади. |
| `Taskfile.yml`, `build/` | Завдання збірки та упаковки. |

## Android межа [#android-boundary]

Постачання VpnService Android забезпечує тунель, а не привілейований процес на робочому столі. `internal/android` передає інтерфейс sing-box, тримає основні сокети поза VPN і повідомляє поточну мережу. Малий Java-хост завантажує спільну бібліотеку Go у додаток WebView.

Дивіться [будівлю](/uk/docs/developers/building), щоб керувати проєктом, та [плагін безпеки](/uk/docs/plugins/security) для межі розширення.
