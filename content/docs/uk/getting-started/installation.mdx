Завантажуйте збірки з [офіційних GitHubрелізів](https://github.com/Rigby-Foundation/NuggetVPN/releases). Використовуйте пакет для вашої операційної системи та процесора.

## Настільна інсталяція [#desktop-installation]

<Tabs items={['Windows', 'macOS', 'Linux']}>
<Tab value="Windows">
Завантажте інсталятор NSIS з розділу Releases і запустіть його. Windows використовує WebView2 для відображення додатку.

Для автоматизованої установки запустіть це у PowerShell:

```powershell
irm https://raw.githubusercontent.com/Rigby-Foundation/NuggetVPN/main/scripts/install.ps1 | iex
```

Скрипт завантажує останню версію, перевіряє SHA-256-хеш, опублікований GitHub, встановлює його та запускає додаток. Повторне його виконання оновлює установку.

Для безконтактної установки використовуйте актив з релізу, що закінчується на `-silent-installer.exe`, або передайте `/S` звичайному інсталятору.
</Tab>
<Tab value="macOS">
Завантажте `.dmg` з Releases і перемістіть **NuggetVPN** до **Застосунки** . Виберіть Apple silicon або Intel для вашого Mac, або універсальну збірку, якщо вона доступна.

Ви також можете скористатися інсталяційним скриптом:

```bash
curl -fsSL https://raw.githubusercontent.com/Rigby-Foundation/NuggetVPN/main/scripts/install.sh | sh
```

Скрипт завантажує і перевіряє реліз перед тим, як встановити та запустити його. Повторне його виконання оновлює додаток.

Якщо macOS каже, що додаток пошкоджений, див. [Усунення неполадок Gatekeeper](/uk/docs/troubleshooting#macos-says-the-app-is-damaged).
</Tab>
<Tab value="Linux">
Виберіть `.deb`, `.rpm` або `.AppImage` з Releases. Додаток потребує GTK 4 та WebKitGTK 6 під час виконання, а також `pkexec` polkit для підвищення прав на робочому столі.

Інсталяторський скрипт вибирає `.deb` або `.rpm`, коли доступні apt, dnf або zypper, і AppImage в іншому випадку:

```bash
curl -fsSL https://raw.githubusercontent.com/Rigby-Foundation/NuggetVPN/main/scripts/install.sh | sh
```

Він перевіряє дайджест релізу, встановлює додаток та запускає його. Повторний запуск оновлює вашу установку.

Для вручну завантаженого AppImage зробіть його виконуваним перед відкриттям:

```bash
chmod +x ./NuggetVPN*.AppImage
```
</Tab>
</Tabs>

## Перший запуск [#first-launch]

Відкрийте додаток як звичайний користувач. На робочому столі перше підключення в кожній сесії додатка запитує права адміністратора для створення мережевого інтерфейсу TUN. Графічний інтерфейс продовжує працювати від імені вашого користувача; тунель працює в окремій службі з правами адміністратора.

Додатку потрібна конфігурація сервера. Продовжуйте з [вашим першим підключенням](/uk/docs/getting-started/first-connection).

## Оновлення [#updates]

Збірки для робочого столу можуть перевіряти наявність оновлень і встановлювати їх всередині додатка. Ви також можете повторно запустити скрипт інсталятора або встановити новішу версію вручну. Збережіть [резервну копію](/uk/docs/guides/backups) перед перенесенням встановлення на інший комп’ютер.

Для Android APK та неподписаного iOS IPA дотримуйтесь [керівництва для мобільних пристроїв](/uk/docs/getting-started/mobile).
