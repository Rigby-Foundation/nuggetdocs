Ці керування застосовуються до робочого столу. Android не надає правил Wi-Fi, глобального ярлика, запуску при вході або командного рядка.

## Глобальний ярлик [#global-shortcut]

Встановіть комбінацію клавіш у **Налаштування → Поведінка → Сполучення клавіш** . Вона підключає або відключає навіть коли вікно приховане, використовуючи останній обраний сервер.

Використовуйте кнопку очищення для видалення ярлика. Оберіть комбінацію, яка не конфліктує з іншими програмами.

## Правила Wi-Fi [#wi-fi-rules]

Відкрийте **Налаштування → Wi-Fi** для керування довіреними іменами мереж.

- **Підключатися в недовірених мережах** підключається до останнього використаного сервера, коли ви приєднуєтесь до Wi-Fi мережі, яка не є надійною.
- **Відключатися в довірених мережах** відключається, коли ви приєднуєтесь до надійної мережі.

Використовуйте **Довіряти** для поточної мережі або додайте назву до списку надійних вручну. Надійна мережа — це та, для якої ви обрали, що VPN не потрібен; її назва не гарантує безпеку.

### Якщо назва мережі прихована [#if-the-network-name-is-hidden]

Деякі операційні системи вимагають дозволу на визначення місцезнаходження, щоб показати назву Wi-Fi. Дозвольте додатку читати її в налаштуваннях конфіденційності системи або введіть назви надійних мереж самостійно. Додаток повідомляє, коли пошук Wi-Fi не підтримується.

## Термінал та скрипти [#terminal-and-scripts]

Командний рядок [контролює вже запущений десктопний екземпляр](/uk/docs/reference/cli):

```bash
NuggetVPN status
NuggetVPN connect Tokyo
NuggetVPN setup Work
NuggetVPN disconnect
```

Додайте `--json` для структурованих результатів і використовуйте коди виходу для виявлення помилок. Додаток можна згорнути в трей, але він повинен залишатися запущеним.

Для змін маршрутизації на основі часу використовуйте [графіки маршрутизації](/uk/docs/guides/routing-setups#schedule-a-setup).
