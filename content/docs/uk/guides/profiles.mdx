**профіль** описує підключення. **підписка** — це URL, який надає колекцію серверів і може оновлюватися, коли постачальник їх змінює.

## Додайте джерело [#add-a-source]

Відкрийте **Профілі та підписки → Додати** і вставте вашу інформацію для підключення.

| Введення | Що відбувається |
| --- | --- |
| HTTP або HTTPS URL підписки | Завантажує підписку постачальника. |
| Посилання для спільного використання протоколу | Створює індивідуальний профіль. |
| sing-box JSON | Імпортує конфігурацію. |
| Конфігурація Clash | Приймається парсером конфігурацій; використовуйте mihomo, коли потрібно запустити повну конфігурацію Clash, як надано. |
| QR-образ | Декодує вміст у діалог додавання для перегляду. |

Діалог додавання рекламує URL-адреси підписки, серверні посилання та sing-box JSON. Якщо формат або протокол не працює, порівняйте його з [довідником протоколу](/uk/docs/reference/protocols) та [основними обмеженнями](/uk/docs/reference/cores).

## Оновити підписку [#refresh-a-subscription]

Використовуйте елемент керування оновленням на її картці в **Профілі та підписки** . Це отримує актуальний список серверів з оригінальної URL-адреси постачальника.

У розділі **Налаштування → Поведінка** , **Оновлювати підписки автоматично** дозволяє оновлення при запуску та за шестигодинним графіком. Постачальник також може запропонувати інтервал оновлення, який ви можете прийняти. Вимкнення автоматичного оновлення підписок відключає автоматичне оновлення для кожної підписки; ручне оновлення залишається доступним.

## Використання, термін дії та повідомлення постачальника [#usage-expiry-and-provider-messages]

NuggetVPN показує дані про доступні дані підписки, їх використання та термін дії лише тоді, коли постачальник включає їх у свою відповідь. Відсутність значень не означає, що підписка має необмежений обсяг даних або відсутність терміну дії.

Постачальники також можуть надавати назву, бренд і оголошення. Вони описують підписку; вони відрізняються від локально вимірюваних лічильників трафіку додатка.

## Ідентифікація підписки [#subscription-identity]

Деякі постачальники обмежують, які клієнти або пристрої можуть отримати підписку. **Налаштування → Ідентифікація клієнта** контролює ідентифікатор клієнта та ID пристрою, що використовуються для цих запитів. Якщо інша дійсна підписка відхиляється, перед зміною цих значень перевірте вимоги вашого постачальника.

## Поділитися, експортувати та видалити [#share-export-and-delete]

Контролі джерела та проксі забезпечують можливість спільного використання та експорту. Список джерел також підтримує вибір кількох записів для оновлення, копіювання, експорту або видалення.

URL підписки, посилання на сервер, QR-код або експортована конфігурація можуть містити облікові дані. Діліться ними лише з тими, хто має право користуватися цим з’єднанням.

Видалення джерела видаляє його з цієї інсталяції. Щоб зберегти повну конфігурацію, спершу [зробіть резервну копію](/uk/docs/guides/backups).
