NuggetVPN — VPN-клієнт для Windows, macOS, Linux, Android та iOS. Додайте підписку, посилання на сервер або файл конфігурації, щоб підключитися до своїх серверів.

<Callout title="Потрібен сервер або підписка">
NuggetVPN є клієнтом. Вам потрібен працюючий сервер або підписка від вашого провайдера, щоб підключитися.
</Callout>

## Знайдіть свій шлях [#find-your-way-around]

| У застосунку | Що ви можете робити |
| --- | --- |
| **Головна** | Запускайте або зупиняйте VPN, переглядайте трафік та проводьте тест швидкості. |
| **Профілі та підписки** | Додавайте джерела з'єднань та оновлюйте підписки. |
| **Сервери** | Шукайте сервери, відзначайте улюблені та вибирайте сервер. |
| **Маршрутизація** | Визначайте, який трафік використовує VPN, йде напряму або блокується. |
| **Активність → Мережеві з’єднання** | Перевіряйте відкриті з'єднання та правила, які до них застосовані. |
| **Активність → Статистика** | Переглядайте використання додатків та стан серверів з часом. |
| **Активність → Журнал** | Читайте діагностику, коли ведення журналів увімкнено. |
| **Налаштування** | Оберіть ядро, налаштуйте додаток і керуйте резервними копіями та плагінами. |

**Активність** групує Підключення, Статистику та Журнали в перемикачі.

Розташування вікна й навігації залежить від платформи та налаштувань вигляду. Назви екранів і налаштувань у посібниках відповідають українському інтерфейсу застосунку.

## Зробіть його своїм [#make-it-yours]

Почніть з [вбудованого ядра](/uk/docs/reference/cores) для найбільшої сумісності. Після підключення використовуйте [посібник маршрутизації](/uk/docs/guides/routing), щоб надсилати конкретні додатки та вебсайти туди, куди ви хочете. Ви можете зберігати різні маршрути як [налаштування](/uk/docs/guides/routing-setups) та перемикатися між ними.

У додатку також є [командний рядок](/uk/docs/reference/cli), [плагінSDK](/uk/docs/plugins), та [інструкції зі складання з вихідного коду](/uk/docs/developers/building). Усі ядра проксі вбудовані в додаток; окремий виконуваний файл ядра не завантажується під час роботи.
