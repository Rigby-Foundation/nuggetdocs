Контент не потребує коду та дозволів: плагін може бути нічим іншим, як `plugin.json` та кількома файлами.

## Теми [#themes]

Теми використовують ті ж числа, що й редактор тем у Налаштування → Зовнішній вигляд. Найпростіший спосіб знайти значення, які вам подобаються, це спершу створити тему там, а потім скопіювати її числа.

```json
"themes": [
  {
    "id": "storm",
    "name": "Storm",
    "mode": "dark",
    "background": { "h": 250, "c": 0.03, "l": 0.14 },
    "accent": { "h": 190, "c": 0.13 },
    "image": {
      "file": "images/storm.jpg",
      "blur": 12,
      "brightness": 0.9,
      "saturate": 1,
      "dim": 0.35,
      "panel": 0.65
    }
  }
]
```

| Поле | |
| --- | --- |
| `id` | Унікально в межах плагіна, у тій самій формі, що й id плагіна. |
| `name` | До 60 символів, відображається у виборі теми. |
| `mode` | `"dark"` або `"light"`. |
| `background.h` | Відтінок сторінки, 0–360. |
| `background.c` | Тон, 0–0.08. 0 — сірий. |
| `background.l` | Світлість: 0–0.3 для темних тем, 0.9–1 для світлих. |
| `accent.h` | Відтінок кнопок, перемикачів та виділень, 0–360. |
| `accent.c` | Насиченість акценту, 0–0.25. |
| `image` | Опційно: зображення позаду додатку. |
| `image.file` | PNG, JPEG, WebP або GIF у плагіні. |
| `image.blur` | Розмиття у пікселях, 0–40. |
| `image.brightness` | 0.3–1.5; 1 залишає все без змін. |
| `image.saturate` | 0–2; 0 — чорно-біле. |
| `image.dim` | Наскільки колір фону теми накладається на нього, 0–0.9. |
| `image.panel` | Наскільки непрозорі панелі додатку поверх нього, 0.2 (скляні) до 1 (непрозорі). |

Значення поза їх діапазоном обмежуються, а не відхиляються. Кольори в OKLCH, а світлість акценту фіксована для кожного режиму, тому текст на кнопках завжди залишається читабельним.

## Шрифти [#fonts]

```json
"fonts": [
  { "name": "Weather Sans", "file": "fonts/weather-sans.woff2" }
]
```

TTF, OTF, WOFF або WOFF2. Кожний шрифт з’являється в списку шрифтів під своєю назвою і пропонується для кожної мови. Літери, яких не вистачає, беруться з резервних шрифтів.

Перевірте, чи дозволяє ліцензія шрифту його розповсюдження.

## Налаштування маршрутизації [#routing-setups]

```json
"routing": [
  {
    "name": "Streaming direct",
    "description": "Netflix, YouTube and Twitch outside the VPN.",
    "file": "routing/streaming.vflow"
  }
]
```

Файл `.vflow` — це цілий граф маршрутизації, той самий файл, який зберігається через Routing → Export. Створіть налаштування в додатку, експортуйте його та помістіть файл у свій плагін. Використання одного з Routing → From plugins замінює маршрутизацію користувача; користувач може відмінити це.

Налаштування, які посилаються на конкретні сервери, втрачають ці посилання на комп’ютері іншої людини, оскільки їхні сервери різні. Правила, що відправляють трафік «через VPN», «прямо» або «блокувати», працюють скрізь.
