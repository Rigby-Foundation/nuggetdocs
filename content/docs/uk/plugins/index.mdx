<Callout title="Обмеження Android">
Сторінки плагінів не працюють на Android. Теми, шрифти та схеми маршрутизації підтримуються.
</Callout>

Плагін — це один файл `.nuggetplugin`: zip-файл із `plugin.json` у його корені. Він може містити:

| | Де він з’являється |
| --- | --- |
| **Теми** | Налаштування → Зовнішній вигляд → Тема, у розділі «З плагінів» |
| **Шрифти** | Список шрифтів у Налаштування → Зовнішній вигляд |
| **Схеми маршрутизації** | Маршрутизація → З плагінів |
| **Сторінка** | Під плагіном, у Налаштуваннях → Плагіни |
| **Фонова сторінка** | Усюди без видимості: вона працює непомітно, поки плагін увімкнено |

Плагін із лише темами, шрифтами та налаштуваннями маршрутизації зовсім не виконує код. Сторінки — це звичайний HTML та JavaScript. Вони працюють у пісочниці і взаємодіють із додатком через невелике повідомлення API, і лише для того, що користувач дозволив при встановленні.

## Швидкий старт [#quick-start]

Найшвидший старт — це приклад у [`examples/plugins/glance`](https://github.com/Rigby-Foundation/NuggetVPN/tree/main/examples/plugins/glance). Він містить картку статусу з кнопкою підключення, тему та налаштування маршрутизації, що блокує поширені трекери:

```
glance/
├── plugin.json
├── icon.svg
├── panel.html
└── routing/
    └── trackers.vflow
```

Скопіюйте його, змініть `id` у `plugin.json` на свій власний і зберіть його:

```bash
go run ./cmd/nuggetplugin path/to/your-plugin
```

Це записує `your-plugin.nuggetplugin` поруч з папкою. Він перевіряє плагін так, як це робить програма при встановленні, тому будь-яка помилка спочатку з'являється тут. Потім встановіть його в **Налаштування → Плагіни → Встановити плагін…** .

Мінімальний плагін, який додає лише тему:

```json
{
  "format": 1,
  "id": "com.example.dusk",
  "name": "Dusk",
  "version": "1.0.0",
  "themes": [
    {
      "id": "dusk",
      "name": "Dusk",
      "mode": "dark",
      "background": { "h": 280, "c": 0.03, "l": 0.16 },
      "accent": { "h": 30, "c": 0.15 }
    }
  ]
}
```
