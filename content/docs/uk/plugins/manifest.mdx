Кожен плагін має `plugin.json` у корені свого zip-файлу.

```json
{
  "format": 1,
  "id": "com.example.weather",
  "name": "Server weather",
  "version": "1.0.0",
  "author": "You",
  "description": "What it does, in a sentence or two.",
  "homepage": "https://example.com/weather",
  "icon": "icon.png",

  "themes": [ … ],
  "fonts": [ … ],
  "routing": [ … ],

  "panel": { "title": "Weather", "file": "panel.html" },
  "background": "background.html",

  "permissions": ["state", "profiles", "notifications"],
  "network": ["status.example.com"]
}
```

## Про плагін [#about-the-plugin]

| Поле | Обов'язково | |
| --- | --- | --- |
| `format` | так | Завжди `1`. Новіша програма може читати нові формати; ця відмовляється від інших і повідомляє про це. |
| `id` | так | Постійний ідентифікатор вашого плагіна. Використовуйте 3–64 малі літери, цифри, `.`, `-` та `_`, починаючи та закінчуючи літерою або цифрою. Добре працює обернений домен: `com.example.weather`. Оновлення повинно зберігати той самий ідентифікатор. |
| `name` | так | До 60 символів. |
| `version` | так | Будь-який рядок версії з літер, цифр, `.`, `+` та `-`, до 32 символів. Показується користувачеві; програма не порівнює версії. |
| `author` | | До 80 символів. |
| `description` | | До 500 символів, показується у вікні встановлення та в списку плагінів. |
| `homepage` | | Адреса `https://`. Показується, але додаток її не відкриває. |
| `icon` | | Файл PNG, JPEG, WebP або SVG у плагіні. Показується квадратним, розміром 36–40 px. |

## Контент [#content]

| Поле | |
| --- | --- |
| `themes` | Користувацькі теми. Див. [content](/uk/docs/plugins/content#themes). |
| `fonts` | Файли шрифтів. Див. [content](/uk/docs/plugins/content#fonts). |
| `routing` | Конфігурації маршрутизації `.vflow`. Див. [content](/uk/docs/plugins/content#routing-setups). |

## Сторінки [#pages]

| Поле | |
| --- | --- |
| `panel` | `{ "title": "…", "file": "panel.html" }`: сторінка, що показується під плагіном у Налаштування → Плагіни. `title` до 40 символів і за замовчуванням використовується назва плагіна. |
| `background` | `"background.html"`: сторінка, яка продовжує працювати, поки плагін увімкнено. |

Див. [сторінки написання](/uk/docs/plugins/pages).

## Доступ [#access]

| Поле | |
| --- | --- |
| `permissions` | Що можуть робити сторінки плагіна. Див. [дозволи](/uk/docs/plugins/security#permissions). Запитуйте лише те, що використовуєте; під час встановлення відображаються всі. |
| `network` | Імена хостів, з якими ваші сторінки можуть контактувати, через `https` та `wss`, наприклад `api.example.com` або `*.example.com`. Інше недоступне. IP-адреси, `localhost` та локальні імена (`.local`, `.lan`, `.internal`, `.home.arpa`) заборонені. Дозволено лише для плагінів із сторінкою. |

## Файли [#files]

Імена файлів можуть використовувати літери, цифри, `.`, `-` та `_`, у папках, розділених `/`. Імена не можуть починатися з крапки. Кожен файл, зазначений у маніфесті, має бути у плагіні з правильним типом розширення.

Плагін може мати максимальний розмір 50 МБ, не більше 500 файлів до 25 МБ кожен та 80 МБ розпакованого стану.

Файли подаються з типом, визначеним розширенням. Інше не подається:

`.html`, `.js`, `.mjs`, `.css`, `.json`, `.svg`, `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`, `.ttf`, `.otf`, `.woff`, `.woff2`, `.txt`
