Плагін може мати дві сторінки, обидві простий HTML:

- a **панель** , що відображається під плагіном у Налаштування → Плагіни;
- фонову **фонова сторінка** , яка працює непомітно, поки плагін увімкнений. Використовуйте її, щоб реагувати на події, наприклад, отримувати сповіщення, коли обривається з'єднання.

## SDK [#the-sdk]

Включіть SDK і використовуйте глобальний `nugget`:

```html
<!doctype html>
<html>
<head>
  <meta charset="utf-8">
  <script src="/plugins/_sdk/nugget.js"></script>
</head>
<body>
  <p id="status">…</p>
  <script>
    const show = (state) => {
      document.getElementById("status").textContent = state.status;
    };
    nugget.call("vpn.status").then(show);
    nugget.on("vpn.state", show);
  </script>
</body>
</html>
```

| | |
| --- | --- |
| `nugget.call(method, params?)` | Викликає метод додатка. Повертає проміс з його результатом або відхиляє з `Error`, повідомлення якого пояснює, що пішло не так. |
| `nugget.on(event, handler)` | Слухає подію. Повертає функцію, яка зупиняє прослуховування. |
| `nugget.fit()` | Просить додаток підлаштувати розмір панелі під її вміст. SDK вже робить це щоразу, коли змінюється розмір сторінки. |

Кожен метод і подія знаходяться у довіднику [API](/uk/docs/plugins/api).

## Виглядає як додаток [#looking-like-the-app]

SDK одягає сторінку в тему користувача та тримає її актуальною:

- **Кольори:** встановлені як CSS-змінні на `<html>`:
  - `--background`, `--foreground`, `--card`, `--card-foreground`;
  - `--primary`, `--primary-foreground`, `--secondary`, `--muted`,
 `--muted-foreground`, `--accent`;
  - `--border`, `--input`, `--ring`, `--destructive`;
  - `--status-connected`, `--status-connecting`, `--status-error`,
 `--status-idle`.
- **Форма:** `--radius`, радіус закруглення кутів додатку.
- **Атрибути:** `color-scheme`, `data-theme="light|dark"`, `lang` та
 `dir` (перська мова йде справа наліво).

Залиште фон сторінки прозорим, і вона розташовується в додатку як частина його:

```css
html { background: transparent; color: var(--foreground); font: 13px/1.4 system-ui, sans-serif; }
button { background: var(--primary); color: var(--primary-foreground); border: 0; border-radius: var(--radius); }
.muted { color: var(--muted-foreground); }
```

Власні шрифти додатку недоступні всередині сторінки; використовуйте системний стек шрифтів або підключіть шрифт у плагіні.

## Розмір [#size]

Панель має таку ж ширину, як картка плагіна, і підлаштовується під свій вміст, висота від 60 до 4000 пікселів. Уникайте `height: 100vh` макетів: кадр приймає висоту того, що в ньому міститься.

## Зберігання даних [#storing-things]

Кожен плагін має власне сховище об'ємом до 1 МБ у форматі JSON, яке зберігається після перезапусків та оновлень і видаляється при видаленні плагіна:

```js
const count = (await nugget.call("storage.get", { key: "count" })) ?? 0;
await nugget.call("storage.set", { key: "count", value: count + 1 });
```

`localStorage` та куки не працюють у пісочниці.

## Що не працює [#what-doesnt-work]

Сторінки працюють у пісочниці; див. [дозволи та пісочницю](/uk/docs/plugins/security). Коротко:

- немає форм (використовуйте JavaScript та `nugget.call`);
- немає спливаючих вікон, `alert` або нових вікон;
- немає вкладених кадрів;
- немає `eval` або `new Function`;
- немає мережі, крім хостів у `network`;
- ніяких скриптів, стилів або зображень з будь-яких джерел, окрім вашого власного плагіна.

Посилання на власні файли плагіна працюють з абсолютними шляхами, 
`/plugins/<your id>/file.png`, або відносними.

## Відлагодження [#debugging]

У збірці для розробки (`make dev`), натисніть Shift + правий клік на сторінці та оберіть 
"Перевірити", щоб відкрити інструменти розробника, потім виберіть frame вашого плагіна 
у селекторі контексту консолі. Вивід `console.log` з’являється там.
