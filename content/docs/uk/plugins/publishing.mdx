## Збірка [#building]

```bash
go run ./cmd/nuggetplugin path/to/your-plugin
go run ./cmd/nuggetplugin path/to/your-plugin out/your-plugin.nuggetplugin
```

Перший записує `your-plugin.nuggetplugin` поруч із папкою; другий 
задіває назву вихідного файлу. У будь-якому випадку, він перевіряє плагін точно так, якби його встановлювали, 
і виводить те, що запитується:

```
Glance 1.0.0: examples/plugins/glance.nuggetplugin (3 KB)
asks for: state, control
```

A `.nuggetplugin` — це звичайний zip, тому будь-який zip-інструмент теж працює, лише б `plugin.json` був у корені, а не в папці. `nuggetplugin` все ще залишається способом переконатися, що він встановиться.

## Версії та оновлення [#versions-and-updates]

Встановлення плагіна з тим самим `id`, що вже встановлений, оновлює його:

- його файли замінюються;
- його сховище зберігається;
- якщо нова версія вимагає дозволів, яких не було в старій, запит на встановлення позначає їх, і користувач має дозволити їх знову.

Додаток не порівнює версії, тому встановлення старішої версії теж працює. Змінюйте `version` для кожного випуску, щоб користувачі могли визначити, яку версію вони мають.

Ніколи не змінюйте `id`: плагін з новим id — це інший плагін, без жодного сховища старого.

## Спільне використання [#sharing]

Помістіть файл `.nuggetplugin` туди, де люди зможуть його завантажити: у випуск GitHub, на вашому вебсайті, у чаті. Плагіни встановлюються з файлу, і програма ніколи не завантажує їх сама.

У описі вашого плагіна або на головній сторінці скажіть:
- що він робить;
- чому йому потрібен кожен запитуваний дозвіл;
- з якими хостами він зв’язується та що надсилає туди.

## Контрольний список [#checklist]

- [ ] `id` належить вам і є постійним.
- [ ] `version` оновлено.
- [ ] Лише ті дозволи, які ви використовуєте.
- [ ] `network` перераховує лише хости, з якими ви контактуєте.
- [ ] Сторінка правильно відображається у світлій та темній темах і в мовах з написанням справа наліво.
- [ ] Шрифти та зображення належать вам і можуть поширюватися.
- [ ] `go run ./cmd/nuggetplugin` пройшов перевірку.
