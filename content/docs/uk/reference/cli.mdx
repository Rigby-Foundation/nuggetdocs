Сам додаток також працює як команда: він управляє копією, що працює, з терміналу, скрипта або гарячої клавіші.

```
NuggetVPN status
NuggetVPN connect Tokyo
NuggetVPN disconnect
```

Додаток має бути запущений (може бути згорнутий у трей). Якщо додаток не запущено, команди повідомляють про це і виходять з кодом 2.

## Команди [#commands]

| Команда | |
| --- | --- |
| `status` | Чи VPN працює, через який сервер, протягом якого часу і трафік. |
| `connect [server]` | Підключається. До сервера за його id, точним ім'ям або частиною ім'я, яке відповідає лише одному серверу. Без параметра підключається до останнього використаного сервера. |
| `disconnect` | Відключається. |
| `servers [search]` | Показує список серверів, поточний відзначено `*`, необов'язково лише ті, чиї імена містять `search`. |
| `setup [name]` | Показує налаштування маршрутизації, активне відзначено `*`, або перемикається на інше за ім'ям. |
| `speedtest` | Виконує тест швидкості через поточний сервер і показує завантаження, відправлення, пінг та джиттер. |
| `help` | Показує список команд. |

Додайте `--json` до будь-якої команди, щоб отримати JSON замість тексту, для скриптів:

```
$ NuggetVPN status --json
{"status":"connected","profile_id":"p-de","profile":"Frankfurt 1","since":1790000000000}
```

## Код виходу [#exit-codes]

| Код | |
| --- | --- |
| 0 | Готово. |
| 1 | Додаток відмовився: такого сервера не існує, не підключено для тесту швидкості тощо. Причина виведена. |
| 2 | Додаток не запущено. |

## Де знаходиться програма [#where-the-program-is]

| Система | |
| --- | --- |
| Windows | `C:\Program Files\Rigby Foundation\NuggetVPN\NuggetVPN.exe`, або там, куди ви його встановили |
| macOS | `/Applications/NuggetVPN.app/Contents/MacOS/NuggetVPN` |
| Linux | `/usr/bin/NuggetVPN` з .deb або .rpm, або сам AppImage |

На macOS псевдонім полегшує задачу:

```bash
alias nuggetvpn=/Applications/NuggetVPN.app/Contents/MacOS/NuggetVPN
```

### Windows [#windows]

NuggetVPN — це віконна програма, а Windows не чекає, поки вони завершаться. У `cmd` запрошення повертається до введення ще до того, як з’явиться вивід. У PowerShell дамп виводу змушує його чекати:

```powershell
& "C:\Program Files\Rigby Foundation\NuggetVPN\NuggetVPN.exe" status | Write-Output
```

Скрипти, що читають вивід або код виходу, або перенаправляють його, працюють як зазвичай.

## Безпека [#security]

Запущений додаток слухає сокет у вашій особистій папці користувача, і кожна команда містить токен із файлу, який може читати лише ваш обліковий запис. Інші облікові записи на тому ж комп’ютері не можуть його використовувати.
