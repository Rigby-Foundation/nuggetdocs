## Додаток та його ядра [#the-app-and-its-cores]

Усі проксі-ядра компілюються у додаток як Go бібліотеки. Жоден виконуваний файл ядра не завантажується і не запускається під час виконання. На робочому столі інтерфейс користувача працює від імені вашого облікового запису і запускає привілейовану копію того ж бінарного файлу для створення та керування тунелем.

Служба ядра аутентифікує сокет-з’єднання за допомогою токена для сесії. GUI створює токен у обмеженому файлі, а підвищена служба читає та видаляє його.

## Жоден HTTP контролер ядра [#no-core-http-controller]

Лічильники та списки активних з'єднань читаються в процесі. Ядра не надають контролер HTTP. Налаштування контролера, запитані конфігурацією Clash, видаляються перед запуском mihomo.

Робочий стіл CLI використовує окремий автентифікований локальний сокет керування для вашого облікового запису. Див. [CLI security](/uk/docs/reference/cli#security).

## Записи та діагностика [#records-and-diagnostics]

- Статистика трафіку зберігається на вашому комп'ютері.
- Релізні збірки стартують із виходу з системи.
- Увімкнення журналювання записує діагностику додатка та ядра на екрані та у файл.
- Вимкнення журналювання також видаляє збережений журнал.

Перегляньте **Налаштування → Конфіденційність** для поточних елементів керування та [monitoring](/uk/docs/guides/monitoring) для діагностичних кроків.

## Зовнішні запити [#external-requests]

Підписки отримуються з URL-адрес, які ви додаєте. Автоматичне оновлення підписок, вимірювання сервера, тестування швидкості, завантаження списків правил, синхронізація та перевірка оновлень виконують мережеві запити під час використання. Постачальники отримують запити, необхідні для обслуговування їхніх підписок та підключень.

Ця сторінка описує поведінку клієнта; вона не встановлює політику ведення журналів або політику конфіденційності для вашого VPN постачальника.

## Плагіни [#plugins]

Плагіни запитують дозволи під час встановлення. Теми лише з контентом, шрифти та налаштування маршрутизації не виконують код. Сторінки плагінів виконуються в ізольованому середовищі та можуть лише викликати дозволені методи додатку або контактувати з оголошеними мережевими хостами.

Доступ плагіна до списку серверів не включає посилання на спільний доступ із обліковими даними. Плагіни не можуть читати файли, налаштування чи журнали, виконувати нативний код або працювати у привілейованій службі. Див. [дозволи плагінів](/uk/docs/plugins/security) для повного контракту.
