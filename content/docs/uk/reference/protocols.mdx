Підтримка протоколу залежить від [обраного ядра](/uk/docs/reference/cores). Використовуйте вбудоване ядро як базу сумісності.

## Серверні протоколи [#server-protocols]

Клієнт підтримує VLESS, VMess, Trojan, Shadowsocks, Hysteria, Hysteria2, TUIC, WireGuard, SOCKS, HTTP та SSH.

VLESS підтримує Reality з XTLS Vision. Вбудована реалізація TodayCore також включає Reality з обміном ключами `X25519MLKEM768` та постквантовим шифруванням VLESS.

## Транспорти [#transports]

Підтримувані сімейства транспортів включають TCP, WebSocket, gRPC, HTTP/2, HTTPUpgrade і XHTTP. Транспорт повинен підтримуватися як обраним ядром, так і конфігурацією сервера.

- **XHTTP:** використовують вбудоване ядро або Xray.
- **Hysteria, Hysteria2, TUIC, SSH:** використовують ядро, відмінне від Xray.
- Плагіни **Shadowsocks:** недоступні через Xray.

## Формати імпорту [#import-formats]

Парсер приймає поширені посилання на протоколи, підписки, повний JSON sing-box та конфігурації Clash. Для повних конфігурацій Clash, mihomo зберігає задуману поведінку виконання Clash.

Діалог додавання може декодувати QR-зображення. `nuggetvpn://` Глибокі посилання та підтримувані посилання для підключення, скопійовані в буфер обміну, також можуть бути запропоновані для імпорту.

Див. [профілі та підписки](/uk/docs/guides/profiles) для роботи з імпортом.

## Непідтримувані профілі rigby [#unsupported-rigby-profiles]

`rigby://` Профілі можуть з’являтися в списку, але не підключаються. Цей протокол існує у форку clash-rs і не реалізований вбудованими ядрами. Отримайте підтримуваний формат підключення від постачальника.
