---
title: "首次连接"
description: "导入订阅或服务器，选择它，并启动隧道。"
---

准备好您的提供商订阅 URL 或服务器共享链接。订阅通常是 `https://` URL。单个服务器链接以协议开头，例如 `vless://`、`vmess://`、`trojan://` 或 `ss://`。

<Steps>
<Step>
### 添加您的连接 [#add-your-connection]

打开 **配置与订阅** 并选择 **添加** ，或者使用应用导航中的添加按钮。在 **添加配置文件或订阅** 中，将链接粘贴到 **粘贴连接链接** 。

对于 HTTP 或 HTTPS URL，按钮变为 **导入订阅** 。对于服务器链接或 sing-box JSON，你可以为配置文件命名并选择 **添加配置文件** 。
</Step>
<Step>
### 选择来源和服务器 [#choose-a-source-and-server]

选择你刚添加的订阅或配置文件。对于包含多个服务器的订阅，打开 **服务器** 并选择一个服务器，或使用自动选择。单个完整配置可能没有单独的服务器列表。

保持 **设置 → 核心** 在 **内置 sing-box** ，除非你的配置需要不同的核心。
</Step>
<Step>
### 连接 [#connect]

打开 **首页** 并按下连接按钮。接受系统的 VPN 或管理员权限提示。在桌面端，此提示会为当前应用会话启动隧道服务。

等待 **已连接** 。连接时显示的服务器是核心实际使用的服务器；仅仅推荐最快的服务器并不意味着 VPN 已激活。
</Step>
<Step>
### 检查连接 [#check-the-connection]

打开一个网站并查看实时流量计数器。你也可以在 **首页** 中运行速度测试，或者在 **网络连接** 下检查请求。

当你想断开连接时，再次按下连接按钮。
</Step>
</Steps>

## 从二维码导入 [#import-from-a-qr-code]

添加对话框可以读取从磁盘选择或粘贴到对话框中的二维码图像。在 Android 上，你也可以使用相机扫描。检查解码后的链接，然后导入它。

## 如果无法连接 [#if-it-does-not-connect]

检查您的订阅是否已过期，尝试其他服务器，并确认所选核心支持该协议。[故障排除指南](/zh/docs/troubleshooting)解释了如何开启日志并缩小故障范围。
