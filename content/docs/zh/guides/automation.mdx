这些控制适用于桌面。Android 不提供 Wi-Fi 规则、全局快捷键、登录时启动或命令行功能。

## 全局快捷键 [#global-shortcut]

在 **设置 → 行为 → 快捷键** 中设置一个按键组合。即使窗口被隐藏，它也会使用上次选择的服务器进行连接或断开。

使用清除控制来移除快捷键。选择一个不会与其他应用冲突的组合键。

## Wi-Fi 规则 [#wi-fi-rules]

打开 **设置 → Wi-Fi** 来管理可信网络名称。

- **在不受信任的网络上自动连接** 当您加入不受信任的 Wi-Fi 网络时，它会连接到上次使用的服务器。
- **在受信任的网络上断开** 当您加入受信任的网络时，它会断开连接。

使用 **信任** 当前网络，或手动将名称添加到受信任列表中。受信任的网络是您选择不需要 VPN 的网络；其名称并不保证安全性。

### 如果网络名称被隐藏 [#if-the-network-name-is-hidden]

某些操作系统需要位置权限来显示 Wi-Fi 名称。在系统隐私设置中允许应用读取它，或自行输入受信任网络名称。当 Wi-Fi 查找不受支持时，应用会报告。

## 终端和脚本 [#terminal-and-scripts]

[命令行](/zh/docs/reference/cli)控制一个已经运行的桌面实例：

```bash
NuggetVPN status
NuggetVPN connect Tokyo
NuggetVPN setup Work
NuggetVPN disconnect
```

添加 `--json`以获取结构化结果，并使用退出代码检测失败。应用程序可以最小化到系统托盘，但必须保持运行。

对于基于时间的路由更改，请使用 [路由计划](/zh/docs/guides/routing-setups#schedule-a-setup)。
