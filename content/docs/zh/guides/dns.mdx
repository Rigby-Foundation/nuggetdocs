## 默认 DNS [#default-dns]

**设置 → 首页 → DNS 服务器** 控制连接期间名称解析的位置。应用程序接受如 `1.1.1.1` 这样的解析器地址。

在更改解析器时，请记住提供商的要求。如果服务器已连接但网站无法加载，DNS 是需要检查的设置之一。

## DNS 的规则 [#dns-for-a-rule]

**路由** 中的域规则可以选择自己的 DNS 解析器。规则的 DNS 字段接受：

| 值 | 解析器 |
| --- | --- |
| `1.1.1.1` | 一个普通的 DNS 服务器地址。 |
| `tls://dns.example.com` | DNS 通过 TLS。将示例主机名替换为您的解析器。 |
| `https://dns.example.com/dns-query` | DNS 通过 HTTPS。使用解析器的实际端点。 |
| `local` | 本地名称解析。 |

这控制匹配域的解析。规则的目的地单独决定结果连接的路由方式。

## MTU [#mtu]

**设置 → 连接 → MTU** 设置隧道传输的最大数据包。应用程序的指南对大多数链路使用 9000，并建议在大文件传输停滞时降低该值。

在诊断问题时，每次只更改一个设置，并比较相同的请求或传输。记下之前的值以便可以恢复它。

## TLS 和混淆 [#tls-and-obfuscation]

**设置 → TLS 与混淆** 包括 TLS 分片、混合 SNI 大小写、记录填充和 SNI 欺骗。这些会影响握手，应根据已知的服务器或网络需求选择。

应用的 TLS 分片和 SNI 设置不适用于 mihomo 或 Xray。请使用内置核心或官方 sing-box 进行这些控制。参见 [核心兼容性](/zh/docs/reference/cores)。
