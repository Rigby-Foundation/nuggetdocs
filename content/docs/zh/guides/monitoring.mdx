## 实时流量 [#live-traffic]

**首页** 屏幕显示从运行核心读取的流量计数器。这些与您的提供商提供的订阅额度和到期值是分开的。

## 打开连接 [#open-connections]

**活动 → 网络连接** 显示正在运行的连接，包括其背后的程序、匹配的规则以及使用的服务器。您可以从此屏幕关闭单个连接。

这是验证路由更改的最佳位置：从应用或网站创建一个新请求，然后检查其匹配的规则和路由。路由命中计数显示当前打开的连接，而不是总计数。

## 统计 [#statistics]

**活动 → 统计** 显示按应用和日期的流量，以及各服务器在过去一天和一周的正常运行时间和延迟。这些统计数据存储在您的计算机上。

## 速度测试 [#speed-test]

在连接时从 **首页** 运行速度测试。它通过当前服务器进行测量。桌面用户还可以运行：

```bash
NuggetVPN speedtest
```

该命令报告下载、上传、延迟和抖动。测试会消耗数据，因此请注意您的服务提供商的限制。

## 日志 [#logs]

在版本发布中默认关闭日志记录。请在诊断问题时，在 **开启日志** ，位于 **活动 → 日志** 下，或在 **设置 → 隐私** 下启用。

1. 打开日志。
2. 重现失败的连接或请求。
3. 打开 **活动 → 日志** 并查看错误。如有需要，可导出相关诊断信息。
4. 完成后关闭日志记录。这样也会删除已保存的日志。

即使界面使用其他语言，日志仍以英文显示。在将导出的诊断信息附加到问题之前，请检查其中的服务器地址、域名和其他私人信息。

有关已保存日志的位置，请参阅 [文件和文件夹](/zh/docs/reference/files)。
