**配置文件** 描述了一个连接。 **订阅** 是一个提供服务器集合的 URL，当提供商更改时可以刷新。

## 添加一个源 [#add-a-source]

打开 **配置与订阅 → 添加** 并粘贴您的连接信息。

| 输入 | 会发生什么 |
| --- | --- |
| HTTP 或 HTTPS 订阅 URL | 下载提供者的订阅。 |
| 协议分享链接 | 创建单独的配置文件。 |
| sing-box JSON | 导入配置。 |
| Clash 配置 | 被配置解析器接受；当您需要运行完整的 Clash 配置时使用 mihomo 。 |
| 二维码图片 | 将内容解码到添加对话框以供查看。 |

添加对话框显示订阅 URL、服务器链接和 sing-box JSON。如果某个格式或协议失败，请将其与 [协议参考](/zh/docs/reference/protocols) 和 [核心限制](/zh/docs/reference/cores) 比较。

## 刷新订阅 [#refresh-a-subscription]

在 **配置与订阅** 中使用其卡片上的刷新控件。这会从原提供者 URL 获取当前服务器列表。

在 **设置 → 行为** 下， **自动更新订阅** 可启用启动时和每六小时的刷新。提供者也可以建议刷新间隔供你接受。关闭自动订阅更新会禁用所有订阅的自动刷新；手动刷新仍然可用。

## 使用情况、到期信息和提供者消息 [#usage-expiry-and-provider-messages]

NuggetVPN 仅当提供商在其响应中包含相关信息时，才显示订阅的数据允许量、消耗情况和到期时间。缺失的值并不表示订阅拥有无限数据或没有到期时间。

提供商还可以提供标题、品牌信息和公告。这些描述订阅，与应用程序本地测量的流量计数器不同。

## 订阅身份 [#subscription-identity]

一些提供商会限制哪些客户端或设备可以检索订阅。 **设置 → 订阅身份** 控制用于这些请求的客户端身份和设备ID。如果一个本应有效的订阅被拒绝，请在更改这些值之前检查提供商的要求。

## 分享、导出和删除 [#share-export-and-delete]

源和代理控制提供共享和导出功能。源列表还支持选择多个条目进行刷新、复制、导出或删除。

订阅 URL、服务器链接、二维码或导出的配置可能包含凭据。仅与那些应该能够使用该连接的人共享。

移除源将其从此安装中删除。要先保留完整配置，请 [保存备份](/zh/docs/guides/backups)。
