一套设置包含完整的路由配置。为家庭、工作或其他用途保持独立设置，并可从 **路由** 或桌面托盘切换。

## 创建并切换 [#create-and-switch]

使用 **路由** 中的设置控件来创建、复制、重命名或删除设置。选择其名称以激活该设置。删除设置会移除其所有规则，并且无法撤销。

在桌面端，您可以在 [命令行](/zh/docs/reference/cli) 中列出或切换设置：

```bash
NuggetVPN setup
NuggetVPN setup Work
```

## 从预设开始 [#start-from-a-preset]

内置预设包括阻止广告和追踪器、阻止 QUIC、直接发送种子，以及绕过某国的 VPN。

查看已添加的规则及其顺序。特别是 **种子直连** 和 **某国家直连** 故意将匹配的流量发送到 VPN 之外。

## 地理数据和远程列表 [#geo-data-and-remote-lists]

服务和国家规则可以使用自定义 GeoSite 和 GeoIP 数据。通过路由地理数据控件管理这些文件。类别建议取决于您已加载的数据。

当您连接时，可以下载远程规则列表，并由核心刷新。编辑器显示其状态并提供 **立即更新列表** 。确保所选择的核心支持该格式：mihomo跳过 sing-box `.srs` 和 `.json` 列表并使用其自身的地理数据。

## 共享 .vflow 文件 [#share-a-vflow-file]

使用 **路由 → 导出** 来保存路由设置，使用 **导入** 来加载设置。一个 `.vflow` 文件包含路由，而不是完整的应用备份。

特定服务器的目标取决于原计算机上的配置文件 ID。其他安装上可能缺少这些引用；导入后请检查它们。通用的 VPN、直接和阻止目的地更容易共享。

插件可以在 **路由 → 来自插件** 提供设置。应用其中一个会替换当前路由，并且您可以撤销该操作。

## 安排一个设置 [#schedule-a-setup]

**路由** 中的计划控件可以按一周时间切换设置。选择设置、工作日以及开始和结束时间——例如 **工作** 从09:00到18:00的工作日。

更改计算机的时间或时区后，请检查计划。应用必须正在运行，其计划控件才能生效。
