NuggetVPN 是适用于 Windows、macOS、Linux、Android 和 iOS 的 VPN 客户端。添加自己的订阅、服务器分享链接或配置文件，即可连接服务器。

<Callout title="需要自备服务器或订阅">
NuggetVPN 是客户端。您需要一个可用的服务器或来自提供商的订阅才能连接。
</Callout>

## 了解应用导航 [#find-your-way-around]

| 在应用中 | 你可以做什么 |
| --- | --- |
| **首页** | 启动或停止VPN，查看流量，并进行速度测试。 |
| **配置与订阅** | 添加连接来源并刷新订阅。 |
| **服务器** | 搜索服务器，标记收藏，并选择服务器。 |
| **路由** | 决定哪些流量使用VPN，直接访问或被阻止。 |
| **活动 → 网络连接** | 检查打开的连接及匹配的规则。 |
| **活动 → 统计** | 查看应用的使用情况和服务器健康状态随时间的变化。 |
| **活动 → 日志** | 在启用日志记录时读取诊断信息。 |
| **设置** | 选择核心，定制应用程序，并管理备份和插件。 |

**活动** 在切换器中将“连接”、“统计”和“日志”分组。

窗口布局和导航位置取决于平台与外观设置。指南中的界面名称与应用的简体中文界面一致。

## 让它属于你 [#make-it-yours]

从 [内置核心](/zh/docs/reference/cores) 开始，以获得最广泛的兼容性。一旦连接，使用 [路由指南](/zh/docs/guides/routing) 将特定应用程序和网站发送到您希望的位置。您可以将不同的路由保存为 [设置](/zh/docs/guides/routing-setups) 并在它们之间切换。

该应用程序还拥有[命令行](/zh/docs/reference/cli)、[插件SDK](/zh/docs/plugins)以及[源码构建说明](/zh/docs/developers/building)。所有代理核心都嵌入在应用程序中；运行时不会下载单独的核心可执行文件。
