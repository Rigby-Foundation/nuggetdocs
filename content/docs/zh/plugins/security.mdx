---
title: "权限与沙箱"
description: "插件权限模型和隔离边界。"
---

一个 VPN 客户端可以看到计算机发送的所有信息，因此插件的构建必须保证安装安全。它们可以为应用添加功能，但绝不会超出用户允许的范围。

## 权限 [#permissions]

安装提示会列出插件请求的每一项权限，以及它可能联系的每一个主机。更新请求更多权限时，会标记新的权限并再次请求。

| 权限 | 允许插件 |
| --- | --- |
| `state` | 查看 VPN 是否启动，通过哪个服务器，以及流量（`vpn.status`、`vpn.traffic` 及其事件）。 |
| `connections` | 查看打开的连接：网站、程序和规则（`connections.list`）。 |
| `profiles` | 查看服务器列表：名称、协议、主机名（`servers.list`）。但绝不会看到包含凭据的链接。 |
| `control` | 连接、断开和切换服务器 (`vpn.connect`, `vpn.disconnect`)。 |
| `import` | 添加服务器和订阅 (`servers.add`, `subscriptions.add`)。 |
| `routing` | 添加路由规则 (`routing.addRule`)。 |
| `notifications` | 显示系统通知 (`notify`)。 |

即使没有任何权限，插件仍然可以显示其页面、读取主题、在应用中显示简短消息，并使用其自己的存储。

## 沙箱 [#the-sandbox]

页面在沙箱内的框架中运行，没有 `allow-same-origin`。页面没有自己的来源，因此无法访问：

- 应用窗口或应用的 Go 方法；
- 其他插件的页面或存储；
- Cookie、`localStorage` 或 IndexedDB。

此外，每个页面都配备了允许的内容安全策略 (Content-Security-Policy)：

- 脚本、样式、图片和字体仅来自插件本身（以及 SDK）；内联脚本和样式可以使用；
- 网络连接仅限于 `network` 中的主机，通过 `https` 和 `wss`；
- 不允许使用表单、嵌套框架、工作线程或插件（`<object>`）。

沙箱还会阻止弹出窗口、对话框、下载以及导航应用窗口。

页面只能通过消息与应用通信。应用会根据插件的权限检查每次调用，并在 Go 中再次检查任何更改操作。

## 插件永远不能做的事情 [#what-plugins-can-never-do]

- 读取服务器链接、设置、日志或磁盘上的任何其他内容。
- 直接更改核心配置或运行本地代码。
- 访问此计算机或本地网络：`localhost`，IP 地址和本地名称不能列在 `network` 中。
- 在应用的特权部分运行任何内容，该部分包含隧道。
- 假冒应用。Toast 通知和提示总是带有插件的名称，并且插件添加的规则会有注释说明。

## 针对用户 [#for-users]

- **安装前：** 查看插件请求的权限。主题不需要任何权限。状态小部件需要 `state`。注意谨慎对待未经充分理由要求 `routing` 或 `import` 的插件：`routing` 可能会将流量发送到 VPN 之外的地方，而 `import` 可能会添加他人控制的服务器。
- **安装后：** 关闭插件会立即停止其页面。删除插件会删除其文件和存储，但它添加的规则仍保留在路由中，并标有其名称。
