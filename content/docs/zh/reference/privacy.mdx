## 应用程序及其核心 [#the-app-and-its-cores]

所有代理核心都已编译到应用程序中作为 Go 库。运行时不会获取或启动任何核心可执行文件。在桌面上，用户界面以您的账号运行，并启动同一二进制文件的特权副本以创建和管理隧道。

核心服务使用每个会话的令牌对套接字连接进行身份验证。GUI 在受限文件中创建令牌，而提高权限的服务读取并删除该令牌。

## 没有核心 HTTP 控制器 [#no-core-http-controller]

计数器和实时连接列表在进程内读取。核心不暴露 HTTP 控制器。Clash 配置请求的控制器设置在 mihomo 运行之前被移除。

桌面 CLI 为您的账户使用单独的已认证本地控制套接字。参见 [CLI 安全](/zh/docs/reference/cli#security)。

## 记录与诊断 [#records-and-diagnostics]

- 流量统计存储在您的计算机上。
- 发布版本从注销开始。
- 启用日志记录会在屏幕上和文件中记录应用程序和核心的诊断信息。
- 关闭日志记录也会删除已保存的日志。

查看 **设置 → 隐私** 了解当前控制，及 [监控](/zh/docs/guides/monitoring) 获取诊断步骤。

## 外部请求 [#external-requests]

订阅内容是从您添加的 URL 获取的。自动订阅刷新、服务器测量、速度测试、规则列表下载、同步和更新检查在使用时会发出网络请求。提供者会接收到为提供其订阅和连接所需的请求。

本页面描述客户端行为；它并不为您的 VPN 提供者制定日志记录或隐私政策。

## 插件 [#plugins]

插件在安装时请求权限。仅内容主题、字体和路由设置不运行代码。插件页面在沙箱中运行，并且只能调用允许的应用方法或联系声明的网络主机。

插件服务器列表访问不包括带有凭证的共享链接。插件无法读取文件、设置或日志，无法执行本地代码，也无法在特权服务中运行。有关完整协议，请参见[插件权限](/zh/docs/plugins/security)。
